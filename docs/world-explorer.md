# 地表观测与太阳系

适用版本：本地 v1.36。作者：Wenshuishi。核对日期：2026-11-08。

操作入口见[使用手册](../使用说明.md#地表观测与太阳系)，验收步骤见[验证指南](verification.md)。本页记录实现和计算口径。

## 主视图与共享时间

`world-explorer.js` 在主观察方式下添加地表观测、太阳系入口，把现有 canvas 暂时移入全幅世界视图；`app.js` 将活动帧交给该视图。地面、太阳系和返回后的轨道共用 `Simulation.time`，不创建第二个世界时钟。时间输入按 UTC+8 解析，真实时间和自定义倍速仍由主模拟状态表达。离开时释放当前视图资源、清除操控输入并恢复原 canvas 和控制器。

地表、太阳系、星际三种世界视图同一时刻只运行一种。地面移动按真实帧间隔推进，天文时间加速不改变按键移动速度。

## 地表位置与高度

`ground-world-math.js` 使用 WGS84 地理经纬度、米制地固坐标及当地东／北／天坐标积分移动。`groundRenderPose` 把同一经纬度和海拔映射到主页6371 km球面；近地网格也使用该球面半径和当地基底，保持与全球地形接合。导航坐标与绘制坐标在明确的适配层转换。

地点 `height` 表示观察者海拔米数。统一自由移动，碰到地面时保留眼高；站立期间精细DEM更新会同步修正接触高度，已在空中的观察者保持输入海拔。DEM 的正高 H 转换至椭球高 h 使用 `h = H + N` 接口；当前没有内置大地水准面网格，采用 **N=0** 近似。该约定同时用于观察者和局部网格，后续可替换 N 而不改变地点记录格式。

`ground-world-surface.js` 从原始2048×1024 ETOPO栅格和已加载的最精细Copernicus栅格取样，不使用512×256全球绘制网格作为接触高度。近、中、远三个采样环共用 `EarthElevation` 队列与缓存，接触需求优先，其余交错加载；驻留数据上限384块与12块全球显示网格预算分开。接触补片256段、半宽4.096–16 km，按离地高度扩大；站在高原仍保留32 m网格间距。周边补片768段，采用中心密、远处疏的非均匀网格，半宽取20–400 km设置值。两级补片边缘衔接实际三角面和全球网格，保持球面曲率。区域网格按16行一批异步构建，期间保留原网格；地点或范围变化会取消旧构建。海拔20 km以上停用接触补片，离地50 km以上停止精细接触请求，区域网格保留至海拔200 km。

高程视锥规划用近侧地表估计屏幕误差，最高山体包络只用于保守可见性判断，避免5 km相机位于9 km包络内部时错误降到全球底图。地面方向的加载范围由共享设置限制；远处逐级细化，不把整个400 km区域都铺成30 m网格。

`shared-world-earth.js` 在地表、太阳系和星际近地视角复用主页地球着色器、日夜纹理、城市瓦片、高程、云、大气与极光资源，视野外细节按需释放。内置和用户下载的城市包通过同一个 `CityTerrain` 管理器按当前相机选取。地表影像提供地面颜色，高程提供起伏；建筑、跑道与车辆碰撞属于后续独立场景能力。

自由移动速度随离地高度平滑增加，并保留按住加速和松开减速。海拔上限为100,000 km；四个高度预设使用对数距离插值，目标为地面、10 km、400 km及20,000 km。

## 卫星影像、缓存与位置地图

`surface-streaming-plan.js` 根据当前相机、离地高度和可视地球范围选取稳定地理区域；`CityTerrain`、原有影像工作线程与缓存负责年度合成的请求、解码和驻留，主页与世界视图借用同一纹理图集。影像默认半径120 km，高程默认160 km，均限制在20–400 km；大范围采用逐级细节并保留已就绪底图。影像沿用Earth Genome的2025年Sentinel-2年度合成和CC BY 4.0署名。

`surface-streaming-controls.js` 将设置同时挂入数据面板和共享地球面板。缓存清理使用请求代次和取消机制，避免晚到请求重新写入刚删除的数据；清理后暂停当前区域自动下载，移动或显式继续后恢复。自动影像缓存与手动离线城市包分开清理，高程使用独立缓存。

`ground-location-map.js` 绘制默认展开的右侧位置图，借用已载入地球底图与城市图集，不产生另一套卫星下载。地图北向上，显示当前位置、朝向、视野扇区、附近地名与公里比例尺，可缩放或折叠；日期线投影作经度包裹处理。

## 天空与太阳系

`shared-world-sky.js` 统一借用主页星表、银河、巡天细节缓存、星图与插画；世界面板修改同一环境设置，地表仅独立保存观察效果和视场。地面天空将当地东／北／天方向与 `earthAxes` 的日期相关惯性坐标连接，日月行星通过现有星历并计入观察者位置。天空自然亮度随太阳高度和月光参数变化；银河、DSS 和文化插画采用现有目录及配准。DSS 是历史巡天影像；当前恒星目录仍采用固定星表位置，未增加逐星自行和周年视差传播。远古年代下的星座形状重建不由本版本实现。

`solar-world-math.js` 使用 Astronomy Engine `HelioState` 的同历元几何日心位置和速度，单位 AU、AU/日，参考轴为 J2000 赤道。月球轨道使用地心 `GeoMoon`，显示时加上地球日心位置。它与地面天空的光行时视位置分开，不能互换作动力学输入。

`solar-world.js` 围绕当前目标作坐标重定位，显示太阳、八大行星、月球和轨道采样；地球姿态沿用 `earthAxes`，观测地点随地球自转。显示增强仅改变天体绘制半径，位置及轨道间距不缩放；关闭后使用物理半径。地球通过共享地球渲染器显示完整图层，月球复用已载入纹理，其余纹理按目标加载，私有驻留最多两份。太阳系背景和标注通过共享星空层绘制。

## 地名与保存

输入即时匹配内置地理目录。点击搜索或按 Enter 显式请求 `https://photon.komoot.io/api/`；发送内容为查询词，网络失败保留内置结果和坐标入口。在线结果依据 OpenStreetMap，展示地点名称及所属地区。

`starorbit-world-v1` 保存最后地点、最多 30 个收藏地点，以及地面导航偏好（速度档、方位、仰角、眼高）和观察效果、视场；星空体系、背景图源和图层由主环境设置统一管理，仅限当前浏览器来源。恢复时校验枚举并限制数值范围；瞬时速度、按键状态、太阳系相机与独立世界时间不写入该键，主时间继续沿用现有主场景状态。当前 PNG 为画面导出，不是可重新载入的飞行存档。

## 验证入口

新增 `tests/ground-world.mjs`、`tests/ground-surface.mjs`、`tests/solar-world.mjs`、`tests/ground-sky.mjs`，并入默认 `npm test`。自动检查覆盖坐标、加减速、地形采样、几何星历，以及多地点多日期的日月地平位置、地球遮挡和昼夜亮度；完整应用的图形、键盘焦点、地图选点、搜索、截图和返回轨道另按[验收步骤](verification.md)执行并记录。

## 地形遮挡与透视观星

地表由 `ground-earth-compositor.js` 复用共享地球网格、瓦片孔洞和相机，先绘制打包距离图，再让大气及云层截断到真实地形距离；默认地面保持不透明。距离预绘制跳过纹理采样与地表光照。仅显式开启 `settings.seeThroughTerrain` 时额外分配颜色目标，将完整地球层以32%不透明度合成；关闭释放该目标，退出释放全部目标。标签按同一距离图遮挡；选择保存于原有世界视图设置，主视图、太阳系和星际不受该开关影响。

## 共享云层与年度夜景

云层沿用主环境的贴图、时次、透明度、昼夜开关、运动和画质参数。观察者在薄云球内时绘制内侧，在外时绘制外侧；画质切换后重新借用主环境网格。薄云和体积云在大气背景之后绘制，使用观察者至云的有限空气路径，地形距离仍负责遮挡；太阳系AU及星际尺度的云深度经过同一坐标适配。

夜景默认选用2025年15角秒（标称500米）Black Marble年度数据，保留2024和2016选项。2025覆盖75°N至65°S，极区由2016底图显示；48×24 AVIF瓦片与低分辨率底图按画质及视野加载，共约126 MiB。该年度图层独立于模拟时间。完整来源见[夜景数据清单](../assets/earth/night-2025-500m/manifest.json)。
