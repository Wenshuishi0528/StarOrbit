# 地表观测与太阳系

适用版本：本地 v1.31。作者：Wenshuishi。核对日期：2026-11-08。

操作入口见[使用手册](../使用说明.md#地表观测与太阳系)，验收步骤见[验证指南](verification.md)。本页记录实现和计算口径。

## 主视图与共享时间

`world-explorer.js` 在主观察方式下添加地表观测、太阳系入口，把现有 canvas 暂时移入全幅世界视图；`app.js` 将活动帧交给该视图。地面、太阳系和返回后的轨道共用 `Simulation.time`，不创建第二个世界时钟。时间输入按 UTC+8 解析，真实时间和自定义倍速仍由主模拟状态表达。离开时释放当前视图资源、清除操控输入并恢复原 canvas 和控制器。

当前两种世界视图同一时刻只运行一种。地面移动按真实帧间隔推进，天文时间加速不改变按键移动速度。

## 地表位置与高度

`ground-world-math.js` 使用 WGS84 地理经纬度、米制地固坐标及当地东／北／天坐标。地面局部网格与相机使用同一套转换，避免沿用旧轨道地球的 6371 km 球面来安放地面观察者；旧轨道场景的球面读数保持原定义。

地点 `height` 表示海拔米数；贴地时为稳定高程样值加眼高，自由升降时为观察者海拔。DEM 的正高 H 转换至椭球高 h 使用 `h = H + N` 接口；当前没有内置大地水准面网格，采用 **N=0** 近似。该约定同时用于观察者和局部网格，后续可替换 N 而不改变地点记录格式。

`ground-world-surface.js` 从 ETOPO 全球底座和 Copernicus 高程栅格取样，地面接触读取高程数据，不读取视觉网格的淡入高度。附近精细网格与远处山势围绕观察者分层生成；局部高程复用已有缓存并按需请求，离开时取消请求和释放网格。地表影像提供地面颜色，高程提供起伏；建筑、跑道与车辆碰撞属于后续独立场景能力。

## 天空与太阳系

地面天空将当地东／北／天方向与 `earthAxes` 的日期相关惯性坐标连接，日月行星通过现有星历并计入观察者位置。天空自然亮度随太阳高度和月光参数变化；银河、DSS 和文化插画采用现有目录及配准。DSS 是历史巡天影像；当前恒星目录仍采用固定星表位置，未增加逐星自行和周年视差传播。远古年代下的星座形状重建不由本版本实现。

`solar-world-math.js` 使用 Astronomy Engine `HelioState` 的同历元几何日心位置和速度，单位 AU、AU/日，参考轴为 J2000 赤道。月球轨道使用地心 `GeoMoon`，显示时加上地球日心位置。它与地面天空的光行时视位置分开，不能互换作动力学输入。

`solar-world.js` 围绕当前目标作坐标重定位，显示太阳、八大行星、月球和轨道采样；地球姿态沿用 `earthAxes`，观测地点随地球自转。显示增强仅改变天体绘制半径，位置及轨道间距不缩放；关闭后使用物理半径。地球与月球复用已载入纹理，其余纹理按目标加载，私有驻留最多两份。

## 地名与保存

输入即时匹配内置地理目录。点击搜索或按 Enter 显式请求 `https://photon.komoot.io/api/`；发送内容为查询词，网络失败保留内置结果和坐标入口。在线结果依据 OpenStreetMap，展示地点名称及所属地区。

`starorbit-world-v1` 保存最后地点、最多 30 个收藏地点，以及地面导航偏好（移动方式、速度档、方位、仰角、眼高）和天空设置（体系、背景、图层、视场、插画亮度），仅限当前浏览器来源。恢复时校验枚举并限制数值范围；瞬时速度、按键状态、太阳系相机与独立世界时间不写入该键，主时间继续沿用现有主场景状态。当前 PNG 为画面导出，不是可重新载入的飞行存档。

## 验证入口

新增 `tests/ground-world.mjs`、`tests/ground-surface.mjs`、`tests/solar-world.mjs`、`tests/ground-sky.mjs`，并入默认 `npm test`。自动检查覆盖坐标、加减速、地形采样、几何星历，以及多地点多日期的日月地平位置、地球遮挡和昼夜亮度；完整应用的图形、键盘焦点、地图选点、搜索、截图和返回轨道另按[验收步骤](verification.md)执行并记录。
