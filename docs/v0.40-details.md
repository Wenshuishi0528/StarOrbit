# v0.40：GitHub Pages 与新手帮助

同一份源码、同一个版本号生成桌面离线版与网页版。离线版由 `npm run build` 输出单文件 HTML；网页版由 `npm run build:web` 输出 `dist/index.html` 和独立资源。GitHub Pages 只发布 `dist/`。

## 在线入口

https://wenshuishi0528.github.io/StarOrbit/

- 首次打开显示欢迎卡，可选择四步导览或直接开始；右上角“？帮助”提供使用说明和重新播放导览。
- 帮助覆盖模型观察、任务切换、时间、小地图与时间轴、地理与星图、数据保存和音乐，支持中英俄法。
- 导览临时展开对应区域，退出后恢复折叠与滚动位置，不更改任务、时间或播放状态。
- 网页默认使用内置轨道与云图；可导入轨道、航天器、云图快照和音乐。需要本机服务的更新入口在网页版隐藏；桌面版保留在线更新。
- 浏览器可能等待一次点击才开始音乐；欢迎卡按钮会接续已选中的随机曲目。
- 设置、导入文件和缓存保存在当前浏览器、当前网站地址下。桌面版与网站分别保存；清除网站数据会清除相应内容。场景文件用于导出与恢复场景，用户模型与音乐通过各自文件导入。

## 构建与发布

`.github/workflows/pages.yml` 在 main 更新或手动触发时运行测试、构建网页并发布。Pages 使用 GitHub Actions 来源；构建读取 package.json 的 displayVersion，无独立网页版版本号。

模型使用 gzip 压缩，纹理和音乐保留原始文件；资源名带内容哈希，相对路径支持仓库子目录。入口约 112 KB，全部可选资源约 178 MB；首次只加载当前启动所需资源，东方红一号、高画质贴图和高清银河按使用加载。构建不降低模型精度或贴图分辨率。

部署命令：

```sh
npm ci
npm test
npm run build:web
node tests/web-build.mjs
```

新增发布前检查验证资源相对路径、gzip 与原 GLB 一致、音乐 SHA-256、轨道数据与版本。浏览器检查覆盖首次导览、跳过与重播、四语帮助、任务延迟加载、最高画质、设置恢复和窄屏布局。结果见 `v0.40-validation.json`。

## English

The web and desktop editions share source code and versioning. GitHub Pages publishes the static `dist/` build with hashed, relative asset URLs. The web edition starts with bundled orbital and cloud data and retains local file imports. A four-step welcome tour and an upper-right help panel support all four interface languages. Browser data stays local to each origin.
