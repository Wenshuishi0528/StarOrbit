# 主页面的巡天望远镜 · v0.98

> **版本专题／历史证据**：本文保留历版设计与当时检查，部分章节含后续补充。现行功能与操作见[使用手册](../使用说明.md)，验证范围见[验证指南](verification.md)。文中的旧版本结果不代表当前版本重新验收；标为源码的链接需联网查看对应提交。

从中国空间站任务右下角「巡天取景」进入，也可在「舱体组合 → 巡天独立飞行」旁打开。首次进入先选择当前轨道位置能看见的星野；右下角在轨道地图和巡天取景之间切换。主画面显示巡天和空间站，小窗显示从巡天真实模型的镜口看出去的方向。拖主画面只转动外部相机。

| 想做什么 | 操作 |
| --- | --- |
| 找恒星 | 输入「织女星」、Vega、天狼星或 HIP 91262，点结果或按回车。可用上下键选结果。 |
| 看星座 | 输入「猎户座」、Orion 或 Ori。巡天转到主要星点的中心，并拉宽视场容纳星座图形。 |
| 自己扫天 | 在取景窗内拖动；点击取景窗后按 W/A/S/D 或方向键微调。滚轮或双指变焦。 |
| 区分焦距与口径 | 拉长等效焦距，视场变窄；增大有效口径，同一曝光下暗星更容易看见。视场角是垂直角。 |
| 保存视野 | 点「拍摄 PNG」取得 1440 × 900 的光学画面，不带文字与十字线。 |
| 看近处 | 展开「空间站、地球与伴飞位置」，可以看空间站、地平线、星下点。「返回星野」恢复先前的星区和焦距，「两器同框」只调整外景相机。 |

**为什么已对准却看不到星？** 搜索以 J2000 天球方向为准。即使目标在地球背面，巡天也会转向它并说明遮挡，不会偷偷更改模拟日期。在地球边缘或空间站翼板附近，只有光路真的被遮住的部分会被挡住。换一个推荐星野、改变观测时间，或为站体遮挡调整伴飞位置，都可以继续观测。

**伴飞位置。** 默认站位在空间站沿轨后方 120 米、轨道法向一侧 60 米、径向外侧 40 米，中心间距 140 米。位置随空间站自身的轨道坐标系推进；调整平面偏移和径向高度后本机记忆，可一键恢复建议位。镜口位于巡天模型一端，至空间站的实际视线距离会随望远镜姿态略变。这是适合同时观察两器的模拟编队，不能据此推定真实任务的站间距离、轨道参数或光学规格。

**星图。** 复用主程序 41,411 颗全天 HIP 恒星，及既有巡天模拟九个深星野的 16,020 颗补充 Tycho-2 星点。搜星共用同一套 J2000 坐标；不同天区的弱星密度会不同。16K 银河底图只提供弥散背景，聚焦后的点光源来自恒星目录。星座轮廓和 Bayer / Flamsteed 编号沿用项目已署名的 d3-celestial 数据，见[数据来源与许可](../assets/D3-CELESTIAL-LICENSE.txt)、[星图数据说明](v0.97-survey.md)及 [搜索别名的来源](https://github.com/Wenshuishi0528/StarOrbit/blob/5ed3d96b52db26f5e9500430eec3a67a32d14f35/assets/xuntian-star-aliases.json)。地表取景使用现有地球昼夜贴图及轨道光照；放大不能恢复贴图本身没有的地面细节。
