# v0.31 · 全局背景音乐

音乐由一个软件级播放器管理。它在启动时独立加载，使用音频自身的时钟；切换航天器、轨道倍速、暂停模拟、导入场景和调整画质都沿用同一条播放流。

## 控件

默认只显示左下角 44 × 44 px 的圆形音符，播放时每九秒旋转一周，暂停、等待声音交互及缓冲时静止。鼠标进入后展开为约 340 × 50 px 的播放条；离开音符、播放条、音量和列表的完整区域后延迟 280 ms 收起。列表与播放条之间保留鼠标通道。拖动排序、调节滑杆和导入文件期间保持展开。

触屏点音符展开，点外部收起。键盘 Tab 可进入播放器并保持展开，Esc 收起并回到音符按钮。系统启用减少动态效果时使用静态图标。摄影模式隐藏播放器界面，音乐继续播放；沉浸模式在左下角保留低透明度入口。

## 播放与音乐库

- 每次启动从现有列表中随机选首曲，之后按用户排序循环。只有一首时循环该曲，列表为空时停止。
- 内置六首用户提供的 M4A，合计约 13 MB；单文件 HTML 总计约 230 MB。原音频保持原样。
- 支持进度拖动、上一首／下一首、播放／暂停、音量、静音、自动播放开关。
- 支持批量导入、按文件内容 SHA-256 去重、拖动排序与上下移动。默认导入标题使用文件名。
- 删除当前曲目后继续播放列表中的下一首；暂停状态下删除会选中下一首并保持暂停。排序当前曲目保持播放位置。
- 内置曲目可从列表移除，恢复按钮重新加入；用户导入的文件保存在浏览器音乐库。删除操作保留电脑上的原始文件。
- 列表更改和导入文件在同一个 IndexedDB 事务中保存，写入失败时保留原列表。
- 同一来源的多个软件标签页通过 BroadcastChannel 交接播放，新标签页成功开始播放后暂停旧标签页。

音乐库位于 `tiangong-music-library-v1`，播放偏好位于 `tiangong-music-settings-v1`。启动不会恢复上一次播放曲目的进度，而是重新随机首曲。恢复默认设置重置播放偏好并保留曲库。

浏览器允许带声自动播放时直接播放；需要交互时在展开条上显示“点击播放”，圆形音符也可执行这次播放操作。相关浏览器行为见 [Chrome 自动播放规则](https://developer.chrome.com/blog/autoplay) 和 [WebKit 自动播放规则](https://webkit.org/blog/7734/auto-play-policy-changes-for-macos/)。

## 代码与验证

`music-library.js` 管理列表规则和原子保存；`music-player.js` 管理一个音频元素及曲库操作；`music-dock.js` 管理悬停、键盘、触屏和拖动状态。音乐实例创建在应用层，任务控制器和环境模块不创建播放器。

测试覆盖六首实际 AAC 解码播放、随机首曲、列表循环、任务切换连续性、场景恢复、导入去重、损坏音频、存储失败、排序、删除续播、刷新、静音与自动播放设置、多个标签页、独立 HTML 离线播放，以及鼠标、滑杆、拖动、键盘与触屏的展开收起。

验证记录见 `v0.31-validation.json`。
