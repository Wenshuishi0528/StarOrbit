# v0.23 云图取样与遮罩诊断

## 结论

GitHub 云图的灰色连块与阶梯状缺口已存在于下载 PNG 的 Alpha 中。原生 8192×4096 图像在南纬 6.67°、东经 146.27°附近的像素检查，以及使用同一图像的普通云／体积云对比，均可看到这些结构。并非仅由体积云生成。上游把红外、Dust RGB 和可见光经过阈值及增强处理后合成透明度；它不是严格的云／晴空分类产品。v0.21 的灰底显示校正不能修复该分类问题。

## 本次修正

体积云在进入可能分歧的射线步进和提前退出前，计算参考云壳的纹理梯度，并用显式 textureGrad 供密度及光照取样共享。避免在不一致控制流中依赖隐式导数。该薄层足迹为近似，不增加纹理、通道或离屏缓冲。

移除密度小于 0.025 就直接归零的硬截断；保留原有云高剖面及数值级空样本跳过。普通云取样与各图源透明度映射不变。尝试过的多点平滑损失云细节，未纳入交付。

## 验证与限制

浏览器 GPU 检查覆盖日照、晨昏、夜间，普通云与体积云，以及窗口调整、HDR 回退。真实 8K 下载图在独立着色器夹具中加载并比较，无着色器编译错误。自动测试和构建另行执行；这些检查验证渲染实现，不代表卫星数据分类准确性。

原图自带的大块灰区仍可能可见。本次没有可靠信息将每个灰像素判断为真实薄云或非云背景，因此不进行全局硬抠、重新绘云或混入不同时间的云图。需要可靠云分类时，可选择软件已有的 NASA 科学云图来源，其观测日期和质量门槛仍按原有流程显示。
