## 文件与运行

- 三种应用内来源均按需下载。下载成功后可预览，再点“使用此云图”；刷新页面先显示模拟器，再恢复上次使用的纹理。GitHub 源文件内容相同可复用本浏览器的已处理图；不把下载时间充作观测时间。
- NOAA、NASA 由桌面服务转换并保存，可在页面重开后接续本机任务或导出快照给网页版。NOAA 小时归档与 NASA 按来源、时次、修订区分。缺测位置按有效性通道显示内置静态图；试算图片中这些区域透明。
- 文件预算指**最终单张贴图**，不包括上游科学字段、导出的 Base64 JSON 或 GPU 解码内存。新的 PNG 以 **30,000,000 字节**为目标，最多 **50,000,000 字节**；超出时先调整编码或分辨率，仍超限则报错。NASA 优先保留逐像素精度，例外量化会记录在元数据。现有文件、导入限制与收藏不会因新预算被清除。
