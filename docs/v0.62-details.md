# v0.62 — 夜面云层光照修复 / Night cloud lighting

## 问题与行为

v0.61 的“夜面也显示云层”把普通云和体积云的太阳光照整体替换成固定白色，并绕过云层的大气处理，因此夜面发白，日面亮度也随开关变化。

v0.62 保留原太阳入射、消光、云内遮蔽、晨昏色彩和大气传输。选项只为夜面增加很弱的月光，不改变云图、密度、透明度或日面亮度。缺少月光时没有额外照明；暗云继续遮挡地表夜灯。普通云与 8K 体积云共用这项逻辑。设置、预设、场景分享和四语说明保留。

## 物理依据与近似

云层在可见光下需要外部光源照明，不应自身保持白亮；月光是反射的太阳光。[NASA：Moonlight](https://science.nasa.gov/moon/moonlight/)；[香港天文台：Colours of Clouds](https://www.hko.gov.hk/en/education/earth-science/general/00349-colours-of-clouds.html)。

- 月球位置取现有 `LunarEphemeris`，按地心视角计算 Lambert 球相位函数。强度采用示意几何反照率 0.12、月球半径与距离的平方比，再乘地球对月球的日照遮挡。
- 着色时计算月球到云点的方向和距离修正，并计入云高、地球地平线、有限月面圆盘遮挡与大气透射；体积云还采样月光方向上的云内遮蔽。
- 只在太阳方向余弦低于 -0.08 时平滑增加弱月光，低于 -0.15 时完全启用；日面和受照晨昏区域不增加照明。
- 夜面选项采用 800 倍的有限可见度增益，输入上限为 0.003（日照量级为 1），方便在日光曝光下观察暗云。它是受月相和方向约束的显示近似，不是绝对光度定标，也不是完整的夜间多重散射、城市上照或自适应视觉模型。既有微弱环境项保持不变。
- 无效时间／状态依旧由模拟器控制；隐藏月球图形、移动相机不会改变云层月光。无月光的夜面可以接近不可见，不保证在所有曝光下清晰显示。

The toggle now adds only weak night-side moonlight instead of replacing solar shading with white. Lunar phase, distance, eclipse and local horizon visibility constrain the contribution. A bounded display gain is used; this is not calibrated radiometry. Daytime pixels remain unchanged.

## 验证

- `tests/cloud-lighting.mjs` 验证月相、距离平方衰减、月食、新月、实际月周期及显示增益上限。
- 全套 `npm test`、离线及网页构建、网页资源检查、`git diff --check` 通过。
- 48 项真实 Chromium/WebGL 检查通过。覆盖 2K、4K、8K 普通云／体积云的 HDR 与兼容路径；日面开关逐像素完全相同，夜面低亮度；无月光或月球被地球遮挡时增量为零，月落过渡连续。
- 浮点渲染目标避免把微弱月光量化到零；JSON 中 mean 为线性 RGB 的 255 倍，不是屏幕感知亮度。既有兼容路径抖动可能出现微小负浮点数，实际显示会裁剪。
- 保存／恢复、刷新、旧场景／预设兼容、总开关与云源关闭、相机独立性和月球显示独立性均通过。详见 [验证记录](v0.62-validation.json)。
- 真实场景拍摄了两类云的日面、夜面和晨昏开关对照：`output/playwright/cloud062-{layer,volume}-{night,twilight,day}-{on,off}.png`。独立 subagent 审查代码和画面，未发现阻断问题。
- 本机 1200×900、8K 体积云夜面整帧 GPU 抽样中，关闭／开启的中位数约 11.98／14.74 ms，P90 约 13.90／20.33 ms，各 8 次、无 disjoint。仅代表此机器与此机位；有效月光样本增加两次有界密度采样，日面或关闭时跳过。见 [性能记录](v0.62-performance.json)。
