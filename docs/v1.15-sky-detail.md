# v1.15 按需高清星空

> **版本专题／历史证据**：本文保留历版设计与当时检查，部分章节含后续补充。现行功能与操作见[使用手册](../使用说明.md)，验证范围见[验证指南](verification.md)。文中的旧版本结果不代表当前版本重新验收；标为源码的链接需联网查看对应提交。

本批完成均衡方案的星空阶段。主画面、巡天取景和照片共享一套影像来源、加载计划和纹理预算；已有银河与行星 JPEG 不变。地表素材沿用原有实现，本批没有扩张地景库。版本为本机 v1.15，未发布 GitHub 或线上网站。

## 使用

- 「地球与星空 → 星空与曝光」与巡天取景中的「按需高清星空」同步。广角保持已有银河，18°以内的放大视场按需访问巡天影像；近期精选小天区也能在主天空出现。
- 点击「查看宇宙悬崖」，或搜索 `NGC 3324`、`宇宙悬崖`、`Cosmic Cliffs`、`JWST`。快捷入口默认以 0.035°视场呈现真实影像内部的细节；继续缩小可看完整范围。地球仍会正常遮挡目标，软件不会为展示图片自动改变模拟时间或绕过遮挡。
- 「影像来源与波段」列出当前已载入的来源、观测日期和署名。「数据与资源 → 高清星空数据」提供来源链接、缓存用量和清理按钮。
- 照片使用自己的输出像素数选择细分级别，同时复用已载入纹理。只做有界预取：若等待期间指向变化，再补一次，最终以实际快门时刻与指向同步绘制；快速扫天或网络失败时，照片明确注明高清未全部就绪，保留可用影像。没有无限等待，也不冻结用户模拟。
- 固定十字线后，拖动、WASD 或方向键会固定新的落点：地面继续跟踪地面点，天空保持惯性方向，站体继续跟随部件。只有主动点击「随轨道转动」才解除；原自由模式下手动转向仍保持自由。
- 取景标注现在优先显示搜索目标或准星附近的天体。名称左右放不下时使用上方、下方等位置；小窗口高倍放大时缩小目录定位框以留出文字位置。仅预览为上下时间/坐标读数留位，不设置准星避让区。照片不留预览读数边距，仍由「照片包含标注」独立控制；分类、目录范围与地球/航天器实际遮挡仍然生效。

## 图源与真实性

| 数据 | 观测年代 | 覆盖与用途 | 格式 |
| --- | --- | --- | --- |
| JWST NIRCam 宇宙悬崖 | 2022-06-03 | NGC 3324 约 7.29 × 4.22 角分；内置近期高清展示 | 原 TIFF 制作成 AVIF |
| Pan-STARRS DR1 i/r/g | 2009–2015 | 北部约 76% 全天；避开不规则南界使用 | 原始 JPEG 瓦片 |
| DSS Color | 约 1975–1999 | 全天覆盖及较粗后备 | 原始 JPEG 瓦片 |

近期包是实际可用的新影像，不代表已经提供 2020 年后的全天高清巡天。韦布是官方红外合成颜色，与 DSS/Pan-STARRS 的光学合成不是同一波段；缩小到原始足迹之外，会看到真实的边界和颜色差异，不用虚构外围或任意模糊掩盖。DSS 在船底座的部分亮星云本来已经接近饱和，不能把其浅亮区域解释为透明缺图。

内置素材由带 AVM/WCS 的官方 10000 × 5791 TIFF 重投影为 293 张 512² HEALPix NESTED AVIF，order 6–13。AVIF 文件合计 **9,850,174 bytes（9.39 MiB）**，含清单、出处和原 AVM 的整个目录约 **9.50 MiB**；66 MB 原片不进入应用。RGB quality 90、4:4:4，足迹 alpha 独立无损并逐块核验。新制作的素材使用 AVIF，所有既有 JPG 和在线 JPEG 不做二次转码。

原图、实际拍摄日期、许可、逐文件 SHA-256 与可重复制作命令见 [素材来源清单](../assets/sky-detail/README.md)。展示和照片保留 NASA, ESA, CSA, and STScI 署名；照片注明红外合成及原图链接。这里是定位到真实天区的展示影像，不能用来代替标定测光数据，也不会把恒星渲染成可见表面。

## 空间、内存与共同渲染

- 磁盘：IndexedDB 压缩文件 LRU，硬上限 **1,000,000,000 bytes**；按视场请求，不下载整套巡天。浏览器配额不足时保留可读缓存，使用最多 16 MiB 的有界内存后备。
- GPU：全局最多 **48** 张 512² RGBA8 纹理，含完整 mipmap 约 **64 MiB**；不是每个窗口各一份。拍照优先于取景，再优先于广角主页面。非可见瓦片释放纹理与位图，关掉共享开关也会释放。
- CPU：常驻解码位图最多约 **48 MiB**；最多 2 个远程和 1 个本地在途请求，解码也计入通道限制。内置影像不会被挂起的网络请求饿死。上述预算不包含软件原有银河/地球纹理、画布、导出渲染目标和浏览器自身开销；AVIF 只减少文件体积，不减少同尺寸解码/GPU像素占用。
- 预取会保留粗级后备；超出瓦片预算时整层降低级别，不截断视场边缘。切换视场取消过时请求；失败、坏缓存、配额不足、清理和关闭有独立处理。
- 影像覆盖对应方向的旧银河和目录星点，避免相同恒星叠亮；行星、星图线、星名和航天器保留独立层次，地球逐像素遮挡。主画面与取景共享色彩/曝光转换；极窄视场使用瓦片相对坐标，避免 GPU 单精度消减造成星点错位。
- IndexedDB 保存 ArrayBuffer 而非长期复用 Blob；缓存键含来源版本与格式，原始瓦片不会因来源变化被错误复用。

## 验证

- HEALPix 以独立 astropy-healpix 参照验证 RA 0°接缝、两极、高级编号、父子关系、保守视场覆盖、UV 和网格；所有 293 张 AVIF 核验尺寸、哈希、透明足迹和全幅回投影。
- 新的管理器与缓存测试覆盖三视图去重、48 张总预算、导出优先级、旧请求/同 key 竞态、clear 屏障、关闭释放、坏缓存回源、离线本地通道、浏览器原生 fetch 接收者和最终快门精确计划。
- 原生 IndexedDB 在 Chrome 156 与 WebKit 27.2 各 14 项检查通过。
- Chrome 实际渲染同一 960 × 600 天区：主画面与巡天照片平均通道误差 **0.257 / 255**；本视场 23 张纹理约 **30.67 MiB**。关闭高清后回退原银河，关闭星空后没有影像残留。
- 原有银河回归仍优先匹配原 16K 素材，而非低分辨率对照：平均亮度误差约 **0.267 / 255**，原图对照误差显著低于降采样图。
- 固定地面后的按键/拖动、固定星空后的微调、显式自由模式、滚转、站体跟踪与部件移除回退均完成真实浏览器验证；窄屏未出现横向溢出。
- WebKit 27.2 在禁止访问在线巡天源的条件下完成真实 AVIF 渲染：仅内置 JWST，14 张纹理约 18.67 MiB，主/取景误差约 0.257 / 255。
- 快捷入口、NGC 3324 搜索、两处共享开关、1440 像素 PNG 下载、统一数据页清缓存与返回取景焦点均通过真实浏览器检查。
- 标注回归覆盖 240–800 逻辑像素宽、0.006°/13.8°、三种密度、Retina、四语言与实体遮挡。真实小窗验证西面纱的搜索居中、固定后拖动、最大变焦、照片包含标注与预览开关独立；最大变焦的名字与实际时间/坐标读数 DOM 矩形不相交。共享布局保持准星区域可用。
- 项目默认 `npm test`、`format:check`、离线/本机/网页三种构建，以及两种拆分构建的资源逐字节校验均通过。离线 HTML 约 390 MB，低于 400 MB 上限；网页入口约 240 KB，资源约 295 MB。
- 新增检查位置：`tests/sky-detail-math.mjs`、`tests/sky-detail-cache.mjs`、`tests/sky-detail.mjs`、`tests/browser/sky-detail.js`；标注补充检查位于 `tests/xuntian-labels.mjs` 与 `tests/browser/xuntian-label-placement.js`。浏览器验证摘要与图片位于忽略目录 `output/playwright/v115-*`。
