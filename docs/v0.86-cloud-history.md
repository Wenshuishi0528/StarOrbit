# v0.86 历史云图

> **版本专题／历史证据**：本文保留历版设计与当时检查，部分章节含后续补充。现行功能与操作见[使用手册](../使用说明.md)，验证范围见[验证指南](verification.md)。文中的旧版本结果不代表当前版本重新验收；标为源码的链接需联网查看对应提交。

入口：**数据与资源 → 云图 → 下载历史云图…**。

1. 选择图源、UTC 日期和时次，点击“查询”。NASA 使用 UTC 整点；北京时间为 UTC+8。VIIRS 使用 UTC 日合成，白天与夜间分别保存。
2. 确认可用后“下载此版本”。已缓存且完整性校验通过的相同选择直接预览，不重复下载。
3. 可预览、收藏保留、导出。NASA 通过覆盖和图像质量检查后才提供手动应用；应用不改变模拟器时间。VIIRS 可打开区域对比，不作为自然云层。

## 图源与限制

- **NASA SATCORPS GCC V2A**：查询指定时次文件头，下载只取必要字段，不下载整个 NetCDF。仍采用 8192×4096 输出、全球/极区覆盖和现有质量门槛。旧版本 V1A/V1B 不自动套用 V2A 解析器；没有文件会明确提示，不用邻近日期代替。上游存在文件不等于一定能通过质量检查。
- **NOAA-20 VIIRS GIBS**：先查官方 WMTS 日期目录，保留日期缺口。下载 2048×1024 全球晴空置信度 PNG，赤道约 20 km/像素，通常约 1–3 MB。晴空置信度不是云光学厚度；日合成也不是某一瞬间的全球天气。透明缺测保留，扫描条带不伪造修复。
- NASA 转换需要桌面启动器本机服务及已有 numpy/Pillow/h5py 依赖。网页版和独立 HTML 可直接请求支持跨域访问的 GIBS；网络限制会显示失败并允许重试。NASA 快照仍可由桌面版导出，再在网页版导入。
- GitHub 增强云图保持暂停。地景/夜景的年份选择和批量历史下载不在本版范围内。

## 保存与可靠性

- 历史数据使用原有 IndexedDB 缓存及容量上限；收藏、当前使用、设置引用的数据不会被自动清理。VIIRS 在历史云图窗口管理，并计入总缓存容量。“清理云图”也包含 VIIRS 预览。
- 新历史图不加入“最新下载”或自动跟随模拟时间的候选；只有明确应用后才固定使用。历史下载不写 NASA 最新检查时间或替换本机最新库。
- 文件经格式、尺寸/覆盖、SHA-256 等检查后才入库。NASA 拒绝结果不覆盖当前图。质量门槛是启发式筛查，不能保证所有图都没有气象或拼接问题。
- 日期目录只缓存 6 小时；重复查询缓存文件不联网。下载过程中可以返回模拟器，完成后仍保存缓存。断网不会自动换日期，可重试同一请求。此版本不承诺浏览器重启后的断点续传。
- NASA 本机仅保留一个临时转换结果供浏览器读取；下次不同历史任务开始时回收。持久历史保存在浏览器，若浏览器仅支持临时缓存会明确提示。

## 验证

`tests/cloud-history.mjs` 检查精确日期、时次、目录缺口、请求参数和自动选图隔离；`tests/cloud-history.py` 检查小范围查询、网络/缺失区分、历史日期不受最新窗口限制、质量拒绝及最新库不受影响。浏览器检查覆盖入口、下载、去重、收藏、持久化、对比和失败保留。

实测（2026-10-30）：官方 GIBS 的 2026-10-28 白天预览下载为 906,555 字节，SHA-256 为 `c15ede024bd24f5e86c5e0f1b3bd007f85f5f685baf656819f76686539b38fde`。NASA GCC V2A 的 2026-10-28 12:00 UTC 文件查询成功，但下载必要字段后发现全球/极区覆盖不足，按设计拒绝入库。正向 NASA 应用流程使用隔离浏览器中的合成测试图验证，不能据此声称真实该时次可用。
