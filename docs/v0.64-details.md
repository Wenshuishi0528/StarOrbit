# v0.64 — 夜云遮挡城市灯光 / Night-cloud city-light occlusion

v0.63 的开关只控制微弱月光。地表灯光的云乘子与云层 alpha 在两种状态下相同，因此开关几乎不可辨。上一版检查黑云自身亮度，未覆盖城市灯光作为背景时的合成结果。

现在开关控制夜云实际消光：开时暗云遮灯，关时深夜无云遮挡；晨昏平滑过渡，日面云层不受开关影响。地表重复的垂直云图乘子已移除，由视线穿过的云层承担遮挡，避免斜视时两份错位阴影。

普通云夜间使用 Beer–Lambert 透射，光学厚度为 10 × coverage² × cloudAmount / max(0.15, |view cosine|)。体积云沿原有路径积分，深夜消光乘 4，透射早停下限为 0.0001；日面仍使用原消光系数和 0.025 早停。关闭夜云时跳过无贡献的夜面密度、光照采样。

这些系数是将云图覆盖度映射到可视遮挡的近似，不是卫星反演光学厚度。薄云、云洞仍透光；夜云自身无人工增亮。地表重复乘子移除后，晨昏少量夜灯也会随正确视线遮挡改变，不能声称其所有像素与旧版相同。

验证采用真实 Earth + cloud 材料与最终 ACES/sRGB/HDR 合成，检查 2K、4K、8K 普通云及体积云的 HDR/兼容路径，两档曝光下的无云/薄云/厚云/选项关闭/浓度零。另检查最亮城市纹理在最大曝光下被厚云遮蔽。检查数值保存到 v0.64-validation.json；实际云图的同时间同视角截图在 output/playwright/cloud064-*-night-{off,on}.png。

The option now changes extinction, not just moonlight. Thick clouds obscure city lights; thin clouds transmit partially; off and zero-density states restore clear night lights. Duplicate ground-level attenuation was removed. Optical-depth mapping remains an illustrative approximation, and daytime illumination is retained.

体积云写入实际可见云点的片元深度，并启用深度测试（不写深度缓冲），避免远侧代理球壳错误遮挡前方航天器。前方/背后标记均有实际屏幕像素回归检查。

完整 npm test、离线及网页构建、网页资源检查通过；54 项光照/设置检查和 55 项遮挡合成检查通过。
