# v0.89 · 实时轨道小地图昼夜显示

> **版本专题／历史证据**：本文保留历版设计与当时检查，部分章节含后续补充。现行功能与操作见[使用手册](../使用说明.md)，验证范围见[验证指南](verification.md)。文中的旧版本结果不代表当前版本重新验收；标为源码的链接需联网查看对应提交。

小地图使用独立的旧版 1K 显示底图，恢复易读的海洋蓝色和海陆层次。此前小地图复用了更新后的地球地表图，再叠加全图暗色，导致白天海洋也接近黑色。现在底图由构建显式打包，不随三维地表来源、云图或曝光调整；旧资源结构仍可回退读取。

夜区使用深蓝色遮罩，在地面太阳高度 0° 到 -6° 之间平滑过渡；白天不再整体压暗。逐像素遮罩取代 5 CSS 像素块，固定大小的画布和像素缓冲重复使用，保持原有 4 Hz 更新与拖动时的节流。

浅色晨昏线配暗色描边，使用模拟器同一太阳方向和地球旋转求出几何地面晨昏圈。绘制在网格上、轨迹下；日期变更线处分开，春秋分的直立边界和两侧日期线副本单独处理。至日的极昼、极夜按实际太阳方向显示。这里表示地面昼夜，航天器受光仍以轨道数据框的直射光和地影状态为准。

图下新增白天、夜晚、晨昏线的小图例。青色过去轨迹、金色未来轨迹和白色当前位置保留，轨迹增加细暗描边以跨越明亮地表和晨昏线。四种界面语言和辅助说明同步。

## 验证

- 自动核对逐像素昼夜侧、平滑过渡、春秋分和至日、两极、日期变更线、230px 小地图尺寸，以及晨昏线每个点与太阳方向正交。
- 资源检查确认独立显示底图优先、旧资源结构可回退，轨迹定位与多语言检查沿用既有测试。
- 完整 `npm test` 通过。浏览器在同一 2026-11-04 时刻对照了新旧效果，并核对 2026 年春分、秋分、夏至与冬至的实际画面。
- 390×844 窄屏展开后，地图和英文图例完整；俄文、法文图例也无横向溢出。键盘前进一步一分钟，以及实际指针拖动后的时间与坐标更新均通过。
- 独立 subagent 未发现未解决的 P1/P2；补查 528 组太阳方向和线段中点，误差小于当前描边宽度。336×168 遮罩加晨昏线纯计算的本机中位约 0.20 ms、P95 约 0.57 ms，此数值不含画布和 3D 绘制。
- 离线 HTML、本机和网页版三种构建通过。完整离线 HTML 约 367 MB，低于现有 400 MB 上限；独立底图约 90 KB。
- 详细子审查见 [v0.89 独立审查](v0.89-minimap-review.md)。

这是一张用于辨认轨道位置的显示地图，不是实时地表观测图。地面晨昏线采用几何边界，不将大气折射、地形和地方日出日落时间混入轨道追踪。
