# v0.85 · VIIRS 云图试验

入口：**数据与资源 → 云图 → VIIRS 云图试验与对比…**。

这是一个独立样本窗口。切换不会写入云图来源设置、当前纹理或下载历史，关闭后继续原来的场景。没有新增后台更新任务，也没有把试验结果作为正式云图源。

## 实际试验内容

- 数据：NASA GIBS 的 NOAA-20 VIIRS **Clear Sky Confidence** 白天与夜间日合成，各一张，日期 **2026-10-28 UTC**。这两张图对应不同过境时刻，不能混合声称为某一时刻的全球天气。
- 原生 L2 云掩膜星下点约750米，但本次轻量预览是 **2048×1024，经纬度网格，在赤道约19.6公里/像素**。界面中的区域查看只重投影/放大这些样本，不增加真实细节。
- day.png：906,555字节；night.png：1,086,029字节；合计1,992,584字节（约1.90MiB）。本机轻量版打开窗口时按需读取；便携版内嵌样本。
- 浅色是低晴空置信度（更可能有云），深红色是高晴空置信度；不是自然色照片。使用NASA原始色表，没有以 `1−晴空置信度` 冒充物理云层透明度。
- 透明区域保持透明，界面用格纹标出；不插值填补缺测、不借用另一日期天气。鼠标读数只对精确匹配官方颜色表的像素报告数值区间，未知重采样颜色不伪造精确值。
- 支持全球、亚洲、跨±180°日期线，以及60°N以北的北极正射投影。内置静态云图仅供外观对比，明确标记没有同日观测时间。

## 初步结论

新源能够给出明确的晴空置信度，避免把普通增强红外图直接解释为云。但这两份样本仍可见扫描条带、重叠边界和缺测：白天样本缺少北极夜间区域，夜间样本也有局部缺测。因此当前只适合试验和判断覆盖，**尚不足以证明可作为完整、无缝、真实透明度的全球云层贴图**。

直接获取 LAADS 的原始 L2 科学文件需要 Earthdata 登录；公开目录样例单个6分钟文件约40–280MB，且预览中并没有原始全部质量位。此次选择官方公开 GIBS 浏览服务，未绕过登录，也未下载原始全球大批量文件。
