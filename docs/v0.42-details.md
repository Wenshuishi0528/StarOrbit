# v0.42 帮助导航与默认画质

- 每个帮助介绍底部提供“上一步”和“下一个”，可直接连续阅读；最后一项点击“完成介绍”退出。
- “选择画质”移到“探索地球与星空”之前，展开后提供“选择整体画质”和“选择星空画质”两个入口。两个介绍分别自动展开左栏并用箭头、高亮框指向实际选择框。
- 快速导览依次介绍观察模型、切换航天器、控制时间、整体画质、星空画质、探索地球与星空、播放音乐。
- 首次使用默认“标准 · 4K”和“4K · 星表观赏”。已有环境设置、收藏和场景继续使用保存的选择。星空内部模式值保持 `view`。
- 整体画质介绍继续推荐“精细 · 8K”；星空介绍说明“观赏增强 · 16K 银河”。中英俄法四语同步。
- 复用原有菜单展开、箭头定位和事件驱动布局，只在相关布局或交互变化时更新；本次没有新增贴图、依赖或逐帧计算。

## 验证

完整自动测试、网页版资源与模型一致性检查通过。浏览器覆盖新用户默认设置、已保存设置重载、两级帮助菜单、完整介绍与快速导览、1440/390/320 像素宽度下的中俄文布局、按钮可见性及画质控件避让。详见[验证记录](v0.42-validation.json)。

独立 subagent 已审查帮助导航、菜单恢复、默认值兼容和计算开销；三语引用的 16K 选项名已统一为下拉框中的实际名称。
