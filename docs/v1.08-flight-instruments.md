# v1.08 驾驶仪表与窗口布局

> **版本专题／历史证据**：本文保留历版设计与当时检查，部分章节含后续补充。现行功能与操作见[使用手册](../使用说明.md)，验证范围见[验证指南](verification.md)。文中的旧版本结果不代表当前版本重新验收；标为源码的链接需联网查看对应提交。

主页面的「航天器姿态 → 显示导航球」用于观察当前航天器本体的姿态。自由飞行则有独立的导航球开关，增加相对速度、目标接口、姿态辅助与对接读数。两种模式复用轻量 Canvas 2D 绘制，不增加 WebGL 上下文或贴图资源。

## 驾驶参考

导航球采用近轨参考：T 为顺轨、N 为轨道法向、R 为径向向外；航向以顺轨为 0°。自由飞行速度标记是相对空间站的速度，主页面标记是惯性轨道速度。机头、旋转和目标标记依据航天器姿态计算，拖动观察相机不改变仪表方向。后方目标用虚线区别，速度过低时隐藏无定义的速度方向。

自由飞行可选相对顺行、相对逆行、朝向原接口和匹配接口姿态。辅助使用有限角加速度，手动转向接管。保持位置与辅助回接仍使用有限平移推力。导航球和历史轨迹可分别关闭；对接相机显示真实相机投影位置、偏移、闭合速度、侧漂与捕获条件。

## 设置与存档

| 设置 | 默认 | 可调范围 |
| --- | --- | --- |
| 平移加速度 | 0.08 m/s² | 0.005–1 m/s² |
| 角加速度 | 3°/s² | 0.1–15°/s² |
| 最大转速 | 6°/s | 0.25–30°/s |
| 对接横向偏差 | 0.30 m | 0.05–1 m |
| 对接姿态误差 | 3° | 0.5–15° |
| 接触总相对速度 | 0.20 m/s | 0.02–0.50 m/s |
| 接触横向速度 | 0.05 m/s | 0.005–0.30 m/s |
| 接触转速 | 0.20°/s | 0.05–3°/s |

RCS 参数按飞船保存，对接容差按飞行任务保存。旧版存档缺少的新字段使用默认值。所有捕获条件同时成立才会完成对接；接口允许的偏移会同步用于实际接口相交豁免，其他结构继续参与碰撞检查。捕获后对齐锁紧的过程采用简化处理。改变容差不会修改旧的独立交会对接教学模块。

精细操纵用于降低手动平移推力与转动响应。关闭角速度抑制后，松开转向键仍会继续转动；开启后用有限角加速度消除转动。自动保持与回接仍使用设定的 RCS 能力。

## 公开资料与模拟取舍

真实对接有有限容差，同时约束相对位置、速度、姿态和角速度。国家航天局说明对接机构会接纳并校正初始偏差、缓冲接触能量，最终锁紧：[飞船对接空间站时，如何做到“稳稳停靠”？](https://www.cnsa.gov.cn/n6758968/n6758973/c10654140/content.html)。中国载人航天办公室的历史介绍给出神舟八号对接约 0.2 m/s 的相对速度约束：[总师讲述新中国载人航天的第一次](https://statistics.cmse.gov.cn/art/2019/8/23/art_19_33272.html)。

这些资料支持“允许非零误差且需要低速接触”的设计。表中设置是本软件的教学与玩法参数，不能当作神舟、天舟或某一种对接机构的完整工程规范；特别是用户扩大的容差只是模拟宽容度。

## 窗口布局

按住浮动小窗口标题栏拖动，释放时保存位置；按钮、输入框和画面拖动保留原操作。显示与视角中可锁定位置、恢复默认布局。窗口尺寸变化后重新限制到可见区域。自由飞行相机按当前面板位置选择可用画面区域，移动界面不会改变飞船的实际姿态。

## 验证

- 用实际 GLB 验证神舟和天舟的离站、同时飞行、手动绕飞、原接口回接、结构碰撞。
- 用约 0.49 m 横向偏差和 5.9° 姿态误差验证 0.5 m／6° 的可调捕获，严格设置拒绝同样接近；验证超速、角速率失败原因与碰撞数据保存。
- 检查导航球方向、后方标记、旋转接口、真实相机投影，以及小屏幕与浮动面板避让。
- 浏览器实际切船后直接使用键盘，改变 RCS 与对接容差、读取仪表、保存并重载任务，确认独立飞船参数与显示设置保留。
- 主页面实际调整本体姿态、拖动观察镜头，检查导航球仅跟随本体；拖动轨道读数、地图、望远镜、音乐与飞行仪表，检查按钮、锁定、重开恢复、布局复位及 390 px 窗口边界。
