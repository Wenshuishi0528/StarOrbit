# v0.44 星轨 · StarOrbit

正式名称：**星轨 · StarOrbit**。中文副标题为“航天与轨道模拟”，英文副标题为“Space & Orbit Simulator”。软件标题、浏览器标题、加载提示、首次导览、中英俄法界面、桌面启动器及当前说明文件统一使用新品牌。

- GitHub 仓库：https://github.com/Wenshuishi0528/StarOrbit
- 在线版：https://wenshuishi0528.github.io/StarOrbit/
- 离线文件：`StarOrbit.html`；启动脚本：`启动星轨.command`；macOS 应用：`星轨.app`。
- 旧 HTML 文件名保留为轻量跳转入口；现有本地服务继续使用相同地址与端口。
- 浏览器存储键、IndexedDB 库、场景格式、任务 ID、云图缓存路径和 macOS bundle ID 保持稳定，以复用已有设置、音乐、模型和快照。已保存的随机种子继续沿用；新用户默认种子使用 StarOrbit。
- 场景与截图等新导出的默认文件名前缀使用 StarOrbit。既有场景文件及用户自定义场景名称继续有效。
- 具体航天器仍使用“中国空间站”“东方红一号”等任务名称；历史更新记录和旧发布包保留当时名称。

构建继续生成同源网页和离线版本。便携打包工具使用新名称，并携带项目许可与许可范围文件。

验证：完整自动测试、网页版资源检查、21 项浏览器检查、旧入口跳转、场景与音乐顺序恢复、macOS 双架构启动器签名及启动检查通过；便携打包检查通过。见[验证记录](v0.44-validation.json)。
