# v0.43 三轴航天器姿态

“航天器姿态”提供 X 滚转、Y 俯仰、Z 偏航三个控制。每轴包含角度输入框和滑条，范围 ±180°，精度 0.1°；模型实时响应，“姿态归零”清除三轴偏移。

中国空间站、东方红一号和导入模型共用这套控制。沿用现有任务姿态数据及场景格式，按任务保存；空间站保持地面轨迹参考，卫星保持当前参考模式和自旋开关。手动偏移采用 Rz(yaw) Ry(pitch) Rx(roll)，在任务参考坐标内绕 X/Y/Z 旋转；模型轴向见“姿态参考”。轨道位置、时间及播放状态不受修改。

输入事件合并到动画帧处理，拖动结束保存设置。固定姿态不重复更新整棵模型矩阵；空间站转动复用已有太阳翼采样和 BVH，仅更新遮挡包围盒和阴影范围；轨道线不因姿态编辑重建。无需新增依赖或模型资源。

## 验证

自动测试覆盖姿态与轨道计算，并补充整体旋转后太阳翼遮挡缓存、翼板继续转动的包围盒回归。浏览器检查覆盖空间站三轴实际旋转、输入与滑条同步、小数和空值、越界处理、归零、任务切换、重开恢复、场景姿态，以及 320/390 像素四语布局；实测编辑期间太阳翼几何与轨道线重建次数均为零。见[浏览器验证记录](v0.43-validation.json)。
