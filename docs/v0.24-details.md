# v0.24 云遮罩与视图控件

## 原因与修正

中国东南沿海的原始 Alpha 裁剪直接显示了截图中的碎片。上游 [Live Cloud Maps 生成器](https://github.com/matteason/live-cloud-maps/blob/main/index.js) 用 visibleDiff < 25 等离散颜色条件决定是否把可见光亮度与红外／Dust RGB 合成结果取较大值。相邻像素跨阈值会造成不连续；本地透明度及体积渲染又会使它更明显。不是只在该地区修改，也没有地理区域硬编码。

处理在原生分辨率进行：先转为现有连续显示透明度，对 5×5 邻域中的高反差跳变施加自适应二项式重建，半径最多两个源像素。平坦及缓变区域保留；低档使用处理后透明度的面积平均，纹理缩小层也在同一标量空间生成。避免在增强灰度上先平均再做非线性转换。阈值与窗口是显示去碎片参数，不是卫星云检测算法。

该处理会柔化突变处的高频细节，不能鉴别每个小云团是否真实，更不能从损失后的合成图恢复观测真值。大片错误灰区、上游镜像极区及图源时效限制仍然存在。没有改写观测时间、引入随机云、替换成另一天的科学图源或修改原始缓存。NASA 与内置图源不应用此处理。

## 性能与兼容

仅加载／切换云图时运行一次 Web Worker，不增加每帧取样。通过 64 行条带读取像素，避免额外整张 RGBA 画布；同一 Weather 实例的加载串行执行，过期排队请求跳过。处理后为 R8 单通道纹理：8K 基础层 32 MiB，含 mipmaps 约 42.7 MiB。普通云、体积云、云影与夜光遮蔽使用同一纹理，不重复透明度转换。历史 PNG 使用 Alpha，旧 JPEG 使用红通道。

## 界面

轨道与时间区域新增“轨道数据框”复选框，数据框右上角 × 可关闭，开关状态独立记忆并纳入恢复出厂设置。原有移动端折叠读数保留。视角菜单默认关闭，只在点击“视角”时展开；选中视角、点外部、焦点离开或 Esc 可关闭。关闭后焦点可回到触发按钮。

## 验证

- CPU 检查：平坦／缓变区域、棋盘噪声抑制、阶跃边界宽度、经度环绕以及独立卷积参考的极区／边界一致性。
- 浏览器真实 8192×4096 下载图：生产 Weather 加载与体积云前后对比，无着色器编译错误；本机加载及处理约 1.0–1.6 秒，非性能保证。
- 中国东南沿海诊断裁剪的平均显示透明度由 0.51676 到 0.51690；这是该裁剪的显示统计，不是云量精度证明。

**English:** The upstream visible-channel threshold produces discontinuous alpha. A bounded, adaptive opacity-space reconstruction reduces high-frequency fragmentation while leaving smooth regions intact. This is display regularization, not recovered meteorological truth; large source errors remain. Processing runs once on load in a worker, retains original archives and isolates NASA/bundled sources. UI controls add persistent telemetry visibility and a collapsed camera picker.

- 完整 HTML 中验证了压缩构建后的 Worker、2K 降档、NASA 分支隔离、控件开关、中英文及刷新后的设置记忆。视角菜单在 390 像素宽视口内未溢出。
- 同一待加载图源请求合并，避免自动历史选择反复使慢加载失效；取消后的旧结果不能覆盖新选择。
