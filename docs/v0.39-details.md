# v0.39：俄法语与连续时间导航

- 新增俄语、法语，顶部使用 中文 / EN / RU / FR 紧凑入口，保存语言选择。菜单、提示、轨道时间、音乐、任务和姿态控制共用同一翻译框架；切换语言保留模拟状态。
- 地理与星图采用原固定版本源中的俄法名称，缺少对应名称时沿用国际名称。地理坐标、边界、北京红色五角星及中国官方边界保持一致。
- 1s／1m／10m／1h 步进可以连续跨天、跨年。播放中步进继续播放，暂停中步进继续暂停；实时模式步进转为自定义 1×。
- 日期输入、实时模式、轨迹、小地图、事件时间轴、场景、收藏和会话恢复使用一致的时间与轨道接口。
- 数据区间内保持原八点星历插值；区间外从最近端点的位置、速度建立开普勒椭圆。状态栏分别显示“星历插值”和“轨道演算 · 开普勒椭圆”。更新轨道文件后使用新数据计算。
- 每组数据仅缓存首尾两组椭圆参数；目标时刻直接求解并按周期约化，无逐步积分、历史扩容或额外下载。事件扫描继续使用单窗口缓存和 4 ms 分批计算。
- 导入的非椭圆或穿地轨道在源数据区间内继续插值，区间外显示“轨道演算不可用”；时间控制仍可操作。
- 日历显示支持扩展年份；时间仅在 JavaScript 日期的表示边界保留采样余量。

## 验证

新增自动检查覆盖双任务首尾连续性、前后 100 年能量与角动量、近圆轨道、未来事件、无效外推处理、扩展年份格式，以及四语言词条和占位符、选择保存、动态错误提示。浏览器检查与 subagent 审查结果记录在 `v0.39-validation.json`。

## English

Russian and French share the existing offline translation and label systems. Continuous time navigation uses ephemeris interpolation within source samples and a cached osculating Kepler ellipse beyond either endpoint. Playback state is preserved, all orbit views use the same evaluator, and storage remains bounded. Language changes preserve the current simulation.
