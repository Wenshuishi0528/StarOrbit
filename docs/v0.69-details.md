# v0.69 — 界面整理与收藏设置隔离

这批修改落实整体审查的第一组问题：设置分组、窄窗口操作和环境收藏对全局偏好的影响。

## 使用变化

- 首次使用只展开“任务选择”和“轨道与时间”，保留已有用户的展开偏好；侧栏顶部增加“全部展开”和“全部收起”。
- “摄影与场景”集中放置摄影模式、普通及 4K 截图、环境与视角收藏、场景分享。曝光仍在“地球与星空 → 星空与曝光”，自适应画质在“性能设置”。组合复位位于“舱体组合”，恢复出厂设置位于“显示与视角 → 重置设置”。
- 窄窗口右上角通过“工具”打开任务实验室、数据与资源、帮助和视角。菜单支持点击外部关闭和 Esc 返回；弹窗关闭后焦点回到可见入口。
- 窄窗口的轨道地图默认收起，按需展开；展开时暂时隐藏轨道读数，收起后恢复。窗口高度不足时地图内部滚动，保留工具入口和时间轴按钮。
- 环境收藏继续恢复画面、时刻、镜头及所引用的轨道快照，但不改写缓存容量、自动清理、更新检查记录、下载来源偏好和自适应性能开关。旧版本收藏使用同一规则。

## 验证

- `npm test` 全部通过。新增测试覆盖实际收藏保存／恢复流程、旧收藏兼容、其他任务的轨道选择保留，以及侧栏默认值、已有偏好和批量操作持久化。
- `npm run build:web`、`node tests/web-build.mjs`、`npm run build` 通过，网页与离线 HTML 均为 v0.69。
- 浏览器实际验证：保存收藏后调整缓存至 600 MB 并关闭自动清理，恢复收藏仍保留这两项设置；窄窗口打开资源面板和任务实验室后能够返回可见工具入口。
- 检查 390×844、422×724、760×600、1280×720 布局及俄语长文本；验证地图展开／收起、时间轴收起、菜单 Esc 返回，以及摄影、沉浸模式进入／退出和跨断点缩放后的画布尺寸。
- 原有控件 ID 全部保留，没有重复 ID。本批没有修改轨道计算、云层光照和资源下载算法。

任务实验室布局和更大范围的性能拆分仍属于后续整理范围。当前版本先同步本机运行目录；GitHub 与在线版发布另行执行。

Existing expansion preferences are retained. Environment presets, including older presets, restore visual state without overwriting global cache, update or adaptive-performance preferences.

The full test suite, web build checks and standalone build passed. Browser checks covered preset restoration, dialog focus, translated labels, compact menus, map and timeline controls, photography and immersive mode transitions, and repeated responsive resizing.
