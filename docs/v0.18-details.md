# v0.18 修改详情与参考资料 — 2026-10-23

本轮包含 8K 大气、晨昏与全球云图更新；本地版本 v0.18，尚未发布到 GitHub。

### 云图来源 / Cloud sources

- 新增「NASA 全球云图 · 含极区」，原生 12960×6480 科学数据转为无损 8192×4096；独立进程分段下载云相位、光学厚度和逐像素时间等必要字段。
- 原选项改名为「github最新已下载」，原缓存和图源保留，两种来源的最新快照分开选取。
- 新源每次更新从最近 30 天每日 12:00 UTC 的 V2A 合成图中筛选全球与两极覆盖合格的数据；先筛云相位再核验完整反演字段，缺测时继续向前查找；移除原先 2024-06-30 NASA 缓存，保留 GitHub 缓存；接入统一更新、历史导入导出及缓存清理。新增单独下载当前云图源按钮。
- 不合格候选缓存 6 小时后重新核验；没有更新的合格云图则保留已有合格数据，并显示实际检查结果。
- 下载与转换失败保留已有缓存；不增加每帧气象处理。来源、处理方法和依赖见 [云图说明](cloud-sources.md)。

**English:** Added a separate NASA GCC cloud source with native-grid, timestamp and polar-coverage checks using a rolling 30-day search of daily 12:00 UTC V2A composites, selective HTTP Range downloads, independent cache selection and lossless 8K output. Existing GitHub cloud downloads are retained.

### 修改前后 / Before and after

| 项目 | 之前 | 现在 |
| --- | --- | --- |
| 大气光路 | 使用简化太阳斜程估算，掠过地平线时精度不足 | 预计算球形大气中的太阳光路，加入臭氧吸收和有限太阳圆盘半影 |
| 晨昏边缘 | 低层易偏白，积分变化可能产生条带 | 沿切点和地影边界分段积分，保留低层暖色与上层蓝色的差别 |
| 观察方向 | 大气已有太阳与视线方向计算，但云层仍采用固定橙色渐变 | 8K 大气、地表直射光、普通云、体积云和海面反光共用 RGB 阳光衰减计算 |
| 轨道视角 | 之前的检查主要集中在朝日地平线 | 在 400 km 高度固定相机位置，比较白天、晨昏、深夜及朝日、侧向、背日九组情况；云顶按高度判断受光，可比地面晚进入地影 |
| 球体轮廓 | 放大后可见地球与云层轮廓折线 | 提高 8K 球体细分，切换档位时释放旧几何体 |
| 内存 | 解析后仍保留大体积内嵌素材 JSON 文本 | 释放 DOM 中的冗余文本，小地图复用已解析地图 |

- 继续使用现有轨道、自由组合和太阳翼计算；4K 及较低档位保留原有着色。
- 共用 256 KiB 光路表；8K 大气每像素最多 48 个样本，性能降档时最多 32 个。离线 HTML 约 211 MB。
- 自动测试与构建通过；轻量浏览器检查通过，普通云和体积云着色器均编译正常。完整大素材应用尚未做本轮长时间压力测试。
- 当前为 RGB 单次散射近似；多次散射、折射和自然气辉未加入。详细核对见 [轨道视角的大气方向性核对](atmosphere-direction-review.md)。

**English:** Improved the 8K atmospheric limb using spherical sunlight optical depths, ozone absorption, finite-sun penumbra and tangent-aware integration. Replaced fixed cloud sunset tints with shared RGB sunlight attenuation for air, terrain, clouds and ocean glint. Checked nine directional/day–twilight–night cases from 400 km altitude. Smoothed high-tier silhouettes and released redundant inline asset text. Tests and build pass; the full-texture application has not undergone a long-duration stress test in this round. This remains a lightweight single-scattering approximation. These changes are local and unreleased.
