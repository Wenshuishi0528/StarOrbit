# v0.70 — 任务实验室工作区整理

## 过境预报

- 顶部摘要显示当前航天器、观测地点及所选预报时段的轨道数据覆盖情况。覆盖判断直接复用预报计算的有效时段规则，区分完整覆盖、仅覆盖部分时段和超出范围。
- 观测地点与预报参数集中在可展开区域。找到过境后自动收起参数，将结果列表和三阶段观测指引带入视野；仍可展开修改并重新计算。
- 未找到过境时保留表单并提示调整时长或最低仰角。时间无效、轨道失效或参数变更时清除旧结果，避免旧结果与新条件混用。
- 数据历元、完整有效区间与观测条件说明集中在“轨道数据与观测说明”。原仰角曲线、时间滑条、日历导出与轨道总览跳转保留。
- 窄窗口选择某次过境后，自动定位到对应观测指引，键盘焦点同步移到标题；当前航天器与地点摘要保持可见。

## 交会对接

- 桌面窗口采用左侧画面、右侧读数和控制的布局。1280×720 窗口中可同时看到画面、六项读数及全部平移和姿态按钮。
- 开始／暂停、重新开始和精细推力保留在上方。起始距离、训练速度及详细说明收进“训练设置与操作说明”。
- 窄窗口采用上下分区，控制区独立滚动，操作下方按钮时训练画面仍保持可见。相机和渲染画布继续随工作区尺寸变化。
- “查看全貌”和重置后的外部取景按空间站、追踪飞船的包围范围及当前窗口比例计算，避免较近起点下模型被裁切。
- 保留原有推力、姿态、惯性、捕获与失败判定；视角按钮补充选中状态，“相机视场”明确为“对接相机视场”。

## 名称与兼容

主界面云图来源采用与资源中心一致的 Live Cloud Maps · GitHub 和 NASA SATCORPS 名称，并标明使用最新已下载数据。来源值、下载逻辑、缓存和已有设置不变。新增文字覆盖中、英、俄、法四种语言。

## 验证

- 完整 `npm test` 通过，包含过境计算、独立轨道对照、对接物理及现有资源和设置回归。
- 网页构建、`tests/web-build.mjs` 与离线 HTML 构建通过。
- 浏览器实际检查北京过境、零次过境、超出轨道范围、部分覆盖及恢复正常条件；检查结果收起表单、选择过境后的定位和设置展开。
- 实测键盘前进与按住姿态按钮，读数随输入变化，暂停后释放全部按住状态。
- 检查 1280×720 桌面、422×724 窄窗口、俄语长文本和跨尺寸切换。没有新增另一套轨道算法或对接动力学。

本批同步本机运行目录和启动器；GitHub 与在线版发布另行执行。
