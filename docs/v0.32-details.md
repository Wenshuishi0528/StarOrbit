# v0.32 · 地影光照与画面清晰度

## 定位

东方红一号的 GLB 保留金属材质，本身没有自发光。v0.29 起，通用模型加载器为每种材质设置了强度 0.35 的 RoomEnvironment 反射，该反射不受轨道地影或辅助照明开关控制。实测全影中太阳光颜色已为零，卫星表面仍被这份反射照亮。此外，辅助照明关闭时还保留了 0.025 的环境光。

对比导入东方红之前的 v0.28 源码，精细档的画布像素比上限仍为 2，没有在卫星接入时调低。修复前 Retina 浏览器实测：862 × 844 CSS 像素，1724 × 1688 绘图像素；航天器画布已有 4× MSAA，但高画质地球／大气 HDR 缓冲为 0×，在合成阶段缺少几何边缘抗锯齿。原实现也只在切换画质／星空时更新像素比，浏览器缩放或跨屏后会保留旧值。

## 修改

- `spacecraft-lighting.js` 统一管理公共展示照明。轨道模式关闭辅助照明时，环境补光为零、展示反射关闭；开启辅助照明或处于模型查看状态时，惰性建立并共用一份展示反射。
- `mission-controller.js` 保留导入的 PBR 材质参数，不再为每个模型绑定室内反射。太阳直射、全影和日出日落颜色继续由既有轨道／大气计算驱动。
- `atmosphere-renderer.js` 为精细档 HDR 缓冲选择浮点颜色 RGBA16F 与深度 DEPTH_COMPONENT24 共同支持的最高 4× MSAA。初始化失败时保留既有 HDR／直接渲染回退路径。
- HDR 与航天器层都保持完整绘图像素尺寸；设备像素比变化时同步画布和星点尺寸，包括无轨道的模型查看。
- 保持模型网格、轨道、自旋速度、纹理和曝光参数。辅助照明开关仍保存在既有场景与会话设置中。

## 验证

运行 `npm test`、实际软件浏览器回归与独立 GPU 大气测试。浏览器回归覆盖四档画质下的全影表面、日照、辅助灯、跨任务反射复用、从模型查看返回轨道、不同设备像素比和 GPU 着色器。

抗锯齿用同一斜边三角形比较 HDR 0× 与 4× 采样：中间覆盖像素由 0 增加至 273。另检查日间蓝色大气边缘、日落、夜侧、普通云／体积云、窗口缩放、缓冲释放及初始化回退。结果见 `v0.32-validation.json`；实际软件截图见本目录的 `v0.32-*.png`。
