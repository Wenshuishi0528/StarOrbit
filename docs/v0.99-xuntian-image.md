# 巡天取景：画质、光照与外景 · v0.99

主页面的巡天取景跟随「地球与星空」中已载入的地表和星空设置。在找到想拍的画面后，可以暂停主时钟仔细观察。改设置、拖动取景和调整曝光仍然有效。

- **看清当前画质。** 取景窗下方依次显示已加载的昼/夜地表底图、银河背景以及实际取景像素。「地表 8K」表示全球贴图宽 8192 像素，「银河 16K」表示六个 4096 像素宽的立方体面所组成的全天影像。缩放无法让低清数据源拥有本来没有的细节。
- **看地球。** 在「空间站、地球与伴飞位置」中选「看日照地表」，巡天会在当前轨道位置可见的地表内寻找受阳光照射的一块。若地球挡住了所有日照地表，界面会说明夜侧状态，并保持模拟时刻。取景时可查看昼面、晨昏或夜面。曝光补偿可以提亮夜景，也可压低明亮地平线。
- **看镜筒转向。** 在取景窗的「外景」一行选「近看巡天」，再在取景窗内拖动、按 W/A/S/D 或搜索天体。外景中看得见巡天机身和镜口一起改变朝向。想重新看见空间站和巡天，选「两器同框」。
- **放大或导出。** 默认小窗保留外景；右上角方框按钮切换为大取景窗。实时预览匹配屏幕像素密度，宽度最高 2048 像素。「拍摄 PNG」旁可选 1440 × 900、2560 × 1600 或 3840 × 2400；拍照时按所选尺寸重新成像，不是把小窗截图放大。
- **星野与星图。** 背景跟随主场景的银河模式。具体的搜星、星座对准和伴飞操作见[巡天望远镜基础操作](v0.98-xuntian.md)。
