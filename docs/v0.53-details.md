# v0.53 · 公开访问统计

网页和本地版本共用一个统计模块。顶部显示“网页累计访问”，同时支持中文、英语、俄语和法语。正式网页记录访问，本地软件、离线 HTML、预览地址和自动化浏览器只读取公开数值。

## 配置与运行

- 统计站点：https://wenshuishi.goatcounter.com 。管理员登录后可查看访问趋势。
- 配置文件：`src/visitor-config.json`，只保存公开站点地址；留空时停用统计。
- 正式计数范围：`https://wenshuishi0528.github.io/StarOrbit/` 和该目录的 `index.html`。
- 固定计数路径：`/StarOrbit/`；切换航天器、轨道、时间和音乐不会产生新计数。
- GoatCounter 设置中启用 **Allow adding visitor counts on your website**。管理后台保持 **Only logged in users**。
- 保留 Sessions 去重；关闭逐次访问明细、来源、浏览器/系统分类、屏幕大小、国家、地区和语言的收集。

模型初始化完成后延迟启动，单次打开最多发送一次计数请求、读取一次公开总数。缓存 15 分钟内重复打开复用数值；没有轮询或动画帧内工作。网络请求 8 秒超时，失败保留缓存，首次无数据时隐藏计数位置。数字的提示文字显示最近成功读取时间。

服务端的公开计数缓存最长约四小时；读取时间代表软件获取该数值的时间。累计数按服务的会话访问口径计算，同一会话内重复访问去重，同一个人在新的会话中可再次计数。

## 请求范围

直接使用服务公开的计数和 JSON 接口，不加载第三方脚本、iframe 或远程代码。

- 写入：`GET https://wenshuishi.goatcounter.com/count?p=%2FStarOrbit%2F`
- 读取：`GET https://wenshuishi.goatcounter.com/counter/%2FStarOrbit%2F.json`
- 请求设置：`credentials: omit`、`referrerPolicy: no-referrer`、`redirect: error`。
- 不提交源码、HTML、模型、轨道数据、导入文件、场景存档、页面标题、网址参数、地址片段、Cookie、密码或 API 密钥。
- 标准网络请求会向服务暴露连接 IP 和浏览器请求头；软件未添加设备标识或用户身份字段。服务按会话机制临时处理 IP/User-Agent 去重。
- 公开响应只接受非负安全整数，使用文本方式显示。

## 验证

覆盖正式地址识别、固定载荷、来源与凭据排除、本地只读、无网络缓存、错误响应、存储受限、国际化，以及桌面和窄屏布局。浏览器测试拦截统计请求并返回测试数字，避免测试数据写入真实服务。
