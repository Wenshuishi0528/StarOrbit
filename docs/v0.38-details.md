# v0.38 · 时间步进

日期输入框下方改为两行控件：第一行选择 1s／1m／10m／1h，第二行后退、暂停／继续、前进。默认选择 1m，选中项使用青色背景。按钮随所选时长显示，例如 −10m／+10m；悬停提示完整中文或英文时长。桌面与窄屏保持单行按钮。

![时间步进控件](v0.38-controls.png)

运行中步进后继续原倍速，暂停时保持暂停。现实时间步进后转为自定义时间，以 1× 继续。到达轨道起点或终点时停在边界并暂停。步进跳转采用已有时间轴定位逻辑，点击后同步下一事件和时间游标。

所选时长写入现有会话设置 `tiangong-session-v1` 的 `timeStep` 字段；旧设置或无效值使用 1m。选择在航天器之间共用，重新打开软件恢复，恢复出厂设置时重置。使用原生单选输入，支持 Tab 聚焦和方向键选择；显示单位为 s、m、h，完整无障碍名称随界面语言切换。

没有新增依赖、素材、数据缓存或逐帧计算。播放速度继续单独控制持续播放快慢，时间轴的键盘左右键保留一分钟步进。

验证：全套 `npm test`，以及 32 项浏览器检查，覆盖四档双向跳转、运行／暂停及倍速、任务共用、实时模式、数据边界、键盘操作、重启恢复、无轨道禁用、中英文提示和窄屏排版。记录见 [v0.38-validation.json](v0.38-validation.json)。
