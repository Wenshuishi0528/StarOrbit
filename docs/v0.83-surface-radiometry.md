# v0.83 · 地表反射率、观测条带与大气

## 已确认的原因

v0.82 的 Sentinel-2 季度合成源中已经存在斜向亮带；关闭大气、直接显示底图时仍能看到。中国西南的宽亮带跨越多个地图细节块，因此不能归因于浏览器细节分块。季度合成并不保证完全去除云、薄云和不同观测条件的影响。

另一问题在颜色流程：此前把经过增益和高光曲线处理的显示 RGB 图作为地表反射率，又交给 sRGB 纹理解码。这会压暗部分地表，并改变、放大明暗差异。不同区域不能通过再加饱和度或局部染色来校正。

## 2026 数据与可复现处理

2026 Q2 选项改用 **NASA MODIS Terra+Aqua MCD43A4 Collection 6.1 NBAR**，通过 [Microsoft Planetary Computer 公共镜像](https://planetarycomputer.microsoft.com/dataset/modis-43A4-061) 获取。NBAR 对观测方向的差异进行 BRDF 归一化；[NASA 产品说明](https://ladsweb.modaps.eosdis.nasa.gov/missions-and-measurements/products/MCD43A4/) 标注原生 500 m、每日产品。每份产品实际综合一个 16 天观测窗口，并不是一天的快照。

固定选择第二季度内每 8 天的产品中心日期，且每个产品的完整观测窗口都必须位于 2026-04-01 至 2026-06-30 内。本次实际窗口覆盖 4 月 1 日至 6 月 27 日，共 307 个源图块、2945 期产品；19 个图块的部分计划日期无产品，均在清单中注明。生产规则为：

1. RGB 使用波段 1、4、3，DN × 0.0001 转为线性反射率。剔除填充值，三通道均有有效质量标记才参与处理。
2. 每日期先在原生 500 m 网格应用 QA，再将有效像元作 2×2 线性平均，得到约 927 m 网格。只要混入低一级 QA，该结果就标为低一级质量。
3. 在约 1 km 像元上，优先取 full BRDF inversion 的日期中值；没有这类日期才使用 magnitude inversion 的有效日期中值。后者是官方产品的较低置信度估计，不冒充同等质量。
4. 在线性域重投影、混合与缩小底图。用标准 sRGB 传递函数保存 JPEG，再由 Three.js 解码回线性反射率参与光照。取消经验增益、饱和度、高光曲线和按地区调色。

缺测和海洋保留 NASA 2004 底图，并仅在缺测/海岸边缘做窄过渡。质量等级、缺测覆盖、每块来源日期与文件哈希写入资源清单。源缓存不进入应用安装包。2004 选项及 2024/2016 夜景选项保留。

本次 288 块细节和四档底图共 **53,626,961 字节（53.63 MB）**。按海陆遮罩和纬度面积加权，约 **68.97%** 陆地采用完整反演、**21.70%** 采用较低置信度反演后备、**9.33%** 采用旧图补充（含缺测边缘过渡）。完整离线 HTML 约 367 MB，分离资源本机版约 275 MB；原始处理缓存不打包。

这仍是可见光波段构成的 RGB 近似与季度合成，不是严格的 CIE 光谱标定照片。观测季节、太阳高度、合成窗口及 2004 原版的地形阴影都会带来差别；不能承诺所有区域完全无云、无接缝，也不能用颜色差直接推断环境变化。

## 大气与地表光照

光照必须在线性空间计算；这是 [Three.js 颜色管理文档](https://threejs.org/manual/pages/color-management.html) 的明确要求。统一相对太阳辐照度为 E = π 后，Lambert 地表直射系数为 E/π = 1，大气单次与多次散射使用相同的 E。去除原先精细大气 ×4、标准大气 ×8、地表 ×1.15 之间的不一致。没有靠修改空气密度、相函数、曝光或云层亮度来匹配截图。

精细画质在线性 HDR 空间合成。当前精细模型仍采用六波段、固定大气、平均地表反照率和简化漫射底光，并不表示已精确还原某地当天的大气或肉眼颜色。标准画质仍使用节省资源的显示空间透明混合近似，这次没有将其冒充完整物理线性合成，也没有增加标准画质的 HDR 缓冲开销。

## 细节边缘与验证

细节缓存仍最多四块。缺少相邻块时仅边缘约两屏幕像素平滑回退；相邻块加载完成后内部和共享边界保持原采样清晰度，并处理日期变更线、极区和多块交点。

独立 CPU 积分与生产 GPU shader 对比：天底正午单次散射参考线性 RGB 为 `[0.01877078, 0.03615139, 0.07594988]`，GPU 为 `[0.01855039, 0.03573103, 0.07512236]`，相对偏差约 1.2%。四档灰板验证了无空气和仅太阳路径衰减；大气方向、地影与云前透射检查通过。另有 13 项生产 GLSL 浮点读回检查验证两种细节网格在部分加载、缺角块和日期变更线处的连续性。最终 18 项日/夜资源切换检查和 14 张固定视角球面对照通过，WebGL 错误为 0。完整测试与本机/离线构建通过。独立复查实际截图反推的大气贡献与密集积分参考一致，未发现重复合成或重复色调映射；精细画质中的蓝色空气散射因此保留。全 552 处相邻重叠边缘平均压缩差约 0.236/255，最坏边缘均差约 1.339/255，未见原规则宽亮条带。少量旧图回退仍可能有局部色差，不宣称全球绝对无缝。

## 复现

使用含 NumPy、Rasterio、Pillow、requests 的 Python 环境：

```sh
python scripts/prepare-day-modis-2026.py --fetch --cadence 8day --out assets/earth/source/day-modis-2026-q2/composites --workers 8
python scripts/assemble-day-modis-2026.py --cache assets/earth/source/day-modis-2026-q2/composites --inventory assets/earth/source/day-modis-2026-q2/composites/inventory.json
python tests/day-atlas.py
python tests/day-color.py
node tests/day-sources.mjs
node tests/earth-radiometry.mjs
node tests/detail-edges.mjs
```

下载支持断点复用，已完成缓存必须通过哈希检查。地表颜色没有根据截图感观逐地区调整。`prepare-day-2026.py` 保留原 Sentinel 数据工具及共用海陆遮罩实现，v0.83 的生产地表由 MODIS 工具生成。
