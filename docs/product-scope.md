## 产品定位与使用者

星轨是以地球轨道航天器为中心的三维航天模拟与观测软件。航天器装配、轨道与姿态、近轨操纵、地球和星空显示、观测摄影及数据管理共用场景和资源。

主要使用者是航天与天文爱好者、科普教学演示者及航天场景摄影用户。开发者可修改源码、导入绕地航天器或接入数据。飞行操纵和对接容差用于教学与玩法；轨道计算、历史重建、真实影像和视觉近似各有对应依据与边界。

以下稳定标识由本次现行实现整理建立，供设计、测试和问题记录引用，不追补为早期需求编号。条件是验收目标，实际结果见[验证与验收](verification.md)及版本执行记录；行为改变时更新条目并保留变更。

| 能力标识 | 范围 | 可验收条件 |
| --- | --- | --- |
| SO-CRAFT-01 | 任务、装配和导入 | 两任务使用各自模型、轨道与姿态；组合可恢复；合法配置/GLB/轨道可导入，非法输入拒绝且保留原场景；切任务保留公共环境。 |
| SO-ORBIT-01 | 时间、轨道与事件 | 时间输入、小地图、事件和读数一致；来源、有效期、插值/外推可区分；区间外共享摄动接续，无轨道时明确提示。 |
| SO-PILOT-01 | 主页面操纵 | 驾驶对象明确；短按、持续按与松开有效；编辑、失焦、切船不遗留推力；遵守1×/10 km限制，退出恢复观测且不改参考轨道。 |
| SO-FLIGHT-01 | 自由飞行 | 神舟/天舟独立离站、切船、碰撞与原口回接；全部捕获条件同时判定；同源保存重开恢复各船参数与状态，加载先暂停。 |
| SO-DOCK-01 | 对接训练台 | 起点、仪表和回放一致；关闭辅助停用对应自动控制；按容差判定接触；可导出JSON/CSV。 |
| SO-OBSERVE-01 | 过境与观测实验 | 使用所选任务的星历；过境有时刻、方向、仰角，支持前后高仰角及昼夜查询（默认≥60°，可调）；曝光、阳台、巡天四格能操作并区分完成/缺格；记录能重开。 |
| SO-TELESCOPE-01 | 巡天与太阳 | 打开默认聚焦巡天；搜索、固定、微调和导航球接管一致；准星实际距离与角偏差分清，未知距离明确；遮挡有效；预览/照片共享资源、照片标注独立；观测/模拟时刻分开，坏快照不替换有效图。 |
| SO-STELLAR-01 | 星际穿梭 | 可靠距离驱动视差和中西三维连线；搜索前往、共用键位加减速、回望太阳、航点和照片；二维／三维导航图共享当前位置、目标、太阳与有界航迹，支持独立地图操作；切换释放资源；恒星J2000快照与模拟时钟分开。 |
| SO-WORLD-01 | 地表观测与太阳系 | 地点、地形高度、当地天空与同一时钟一致；共用移动键、持续加速及失焦清空；地面／太阳系切换保持时刻；几何行星位置与显示增强分开；退出释放视图并恢复轨道。 |
| SO-EARTH-01 | 地景与高程 | 内置城市离线可用；下载/取消/删除有明确结果；1×高程与照片共享；反复开关不破坏独立地理标注；缺测明确回退。 |
| SO-SKY-01 | 星空与目录 | 主画面、巡天、照片共享体系/来源/类别，赤道网和黄道随所选日期更新；中西切换保留时间和天球方向，搜索、成员图与名称连线一致；旧场景缺省西方，中国体系不造宿界；目录对象、教学图像与影像天区分开，关闭/切换释放不再使用的资源。 |
| SO-LUNAR-01 | 地面月球观测与真实三维月面 | 同一日期/地点驱动月相与视盘；真实地形、9,087 条正式地名、39 处可定位着陆点及中科院地质纹理共用经纬坐标；40 项任务含一项坐标未知记录。模式、辅助光和倍率明确，支持搜索、独立标注开关、导出和巡天动态追踪。 |
| SO-COSMIC-01 | 极端天体与现象教学 | 五主题独立时间与参数；示意／观测区分；脉冲几何与曲线一致；真实目标不冒用物理身份；暂停、离开与释放有效，导出带参数和说明。 |
| SO-RESOURCE-01 | 资源恢复 | 检查、下载、应用分开；来源失败独立；取消/删除/切换后迟到数据不重写；清理保护活动与收藏，失败保留有效旧数据。 |
| SO-SAVE-01 | 保存边界 | 同源重开恢复约定内容；场景、偏好、飞行存档分开；缺快照明确提示；不能持久写入时不声称永久保存。 |
| SO-DELIVERY-01 | 分发与文档 | 入口/产物版本一致；运行能力符合下表；包内文档、图片、许可及链接可用；帮助对应当前控件且不改任务状态。 |

## 运行方式与功能差异

三种用户运行方式共用核心界面，网络、存储和本机接口不同。源码开发版用于构建这些产物。

| 功能 | 在线静态版（HTTPS） | 便携单文件（直接打开 file://） | 本机服务（启动器/localhost） |
| --- | --- | --- | --- |
| 模型、基础环境、轨道与操纵 | 先取得网站资源；实际离线能力取决于浏览器已载入资源，不承诺首次离线打开网站 | 运行所需内置素材嵌入 HTML，断网可启动内置场景 | 由本机入口和资源目录提供，不需为启动再下载网络素材 |
| 内置城市、精选 JWST 和全球高程底座 | 随网站资源加载；需先完成所需文件获取 | 内置资源可离线使用 | 本机文件提供内置资源 |
| 直接联网资源 | 浏览器可直接访问的云图、极光、星空、城市和高程源按需请求，受覆盖、CORS和网络限制 | 直接请求同样受源站和浏览器对 file 来源的限制；不保证与 HTTPS 相同 | 同类资源仍需源站可用；本机服务不补造缺失数据 |
| NASA/NOAA/向日葵云图的本机处理 | 无本机处理接口，可导入已有成品快照 | 无本机处理接口，可导入已有成品快照 | 本机服务负责相应下载、转换和磁盘库；可选 Python 依赖须就绪 |
| SDO太阳影像更新 | 导入已导出的太阳快照 | 导入已导出的太阳快照 | 通过同源本机接口按当前波段更新 |
| 官方轨道更新 | 尝试源站直连，可能被源站或CORS阻止；可导入轨道 | 直连限制同左；没有 localhost 中继 | 固定来源的本机中继与源站请求；失败保留有效旧数据 |
| 设置、快照与下载包 | 保存在该浏览器和网站来源 | file 来源的存储隔离和配额取决于浏览器；须实测重开 | 保存在所用浏览器和localhost地址；本机云图库另存磁盘 |
| 包内文档和开发工具 | 仓库/网站文档入口；部署范围以实际构建为准 | 发布包附说明、参考文档和许可；不包含完整开发测试环境 | 发布包/源码中的说明与服务脚本；开发测试需源码和依赖 |

更换浏览器、主机名、端口或路径可能进入不同存储范围，同一电脑上的不同入口也不自动共享存档。本机接口使用固定来源；依据 `src/runtime-assets.js`、`src/orbit-repository.js`、`src/solar-data.js`、`src/cloud-library.js` 和 `scripts/serve.py`。

## 三种操纵方式

| 项目 | 主页面近轨操纵 | 独立自由飞行 | 交会对接训练台 |
| --- | --- | --- | --- |
| 用途 | 在观察场景中探索当前任务航天器或巡天的姿态与附近相对运动 | 从当前空间站组合出发，驾驶神舟/天舟离站和回接 | 在教学场景练习末段对准、接近、偏差恢复或随机起点 |
| 模型与时钟 | 当前参考轨道附近的HCW相对运动、四元数姿态；实际操纵转为1×；10 km偏移限制 | 从开始时位置/速度构造参考轨道，近站相对运动；独立任务时钟 | 400 km圆参考轨道上的HCW相对运动与训练规则；实验时钟 |
| RCS/SAS | 默认RCS关、SAS开；RCS允许平移，SAS用有限控制抑制转动 | 默认RCS开；逐船设置推进和姿态参数 | 自动控制与相对制动受新手辅助开关限制 |
| 惯性与制动 | 松键不清零速度；SAS不消除平移漂移，相对制动是独立有限推力操作 | 松键继续漂移；辅助回接可被手动接管，结构碰撞继续检查 | 纯手动关闭自动阻尼、制动和教学停靠点辅助 |
| 状态与保存 | 运动瞬态只在本次页面中存在；改时间/倍速/任务或转自由飞行会结束演练 | 独立存档保存多船状态、接口、参数和显示设置；重新读取先暂停 | 训练记录可回放并导出JSON/CSV；不等同自由飞行存档 |
| 范围 | 参考轨道线和地面预测仍是原轨道，当前观测星历不被改写 | 当前支持原接口回接、锁定后再离站；容差为可调模拟参数 | 独立教学训练，不代表当前空间站组合的全部真实机构 |

主要姿态/平移键位统一，输入属于所聚焦区域；观察镜头、驾驶对象和巡天光轴分别选择。F临时切换SAS，遵守训练辅助限制。依据 `src/main-flight.js`、`src/main-flight-physics.js`、`src/free-flight.js`、`src/free-flight-store.js`、`src/docking-physics.js` 和 `src/docking-training.js`。

## 存储、离线和清理范围

持久化受来源、配额和清网站数据影响。缓存预算约束应用管理范围，不保证永久保留，也不是进程内存上限。

| 内容 | 保存与离线含义 | 转移或清理边界 |
| --- | --- | --- |
| 偏好、组合、时间、相机、面板 | 当前浏览器来源保存；主页面演练瞬态不保存 | 场景可携带所定义的场景状态；语言与界面偏好独立；恢复出厂不等于删除全部库 |
| 场景文件 | `.starorbit.json`保存任务、组合、轨道、时间、相机和环境配置 | 天气通常引用快照标识；缺少资源时提示并回退；需精确复现时另传对应资源快照 |
| 导入航天器与音乐 | 浏览器模型/音乐库保存，保留原文件便于重新导入 | 不把普通场景文件当作导入素材的完整备份 |
| 自由飞行存档 | 独立localStorage记录；写入失败时当前页面仍有临时副本 | 同源重开依赖持久写入成功；不包含在普通场景导出中 |
| 观测记录 | 保存观测时的数据和参数，用于重开实验 | 属于本机浏览器记录；以实验内实际提供的保存/导出入口为准 |
| 云图、极光和轨道快照 | 浏览器数据库按类型管理；保护当前使用、收藏和被引用记录 | 导入/导出相应快照；NASA公共云图库另存本机磁盘，浏览器预算不会自动删除全部本机文件 |
| 太阳快照 | 四波段各保留最新有效影像，总预算32 MiB；已有图可离线使用 | 可导入/导出太阳快照；不提供任意日期太阳活动的自动历史库 |
| 城市高清影像 | 北京、西雅图内置；其他城市可主动下载离线包；压缩缓存预算512 MiB | 自动缓存按城市管理，用户显式保存的离线包不自动淘汰；用户可逐城删除，清网站数据仍可能丢失 |
| 按需高清星空 | 自动分块缓存上限1,000,000,000 B（十进制1 GB）；内置JWST天区不依赖该网络缓存 | 自动淘汰旧块；当前未缓存或已淘汰天区离线回退可用底图；无法持久存储时用有界临时内存 |
| 真实高程 | 全球粗底座内置；局部采样高程自动缓存128 MiB | 按最近使用淘汰，不是用户固定的离线地区包；清缓存保留内置底座，开启地形时可重新请求当前区域 |

本机云图库的默认位置为 `~/Library/Application Support/Tiangong Orbit Simulator/clouds`。清理云图时应阅读界面给出的本机/浏览器范围；云图库的“删除此云图”明确删除当前浏览器与对应本机文件；正在使用时先切内置云图。最新/收藏保护用于自动清理，不阻止确认后的手动删除。存储依据包括 `src/weather-cache.js`、`src/scene-share.js`、`src/free-flight-store.js`、`src/solar-data.js`、`src/city-terrain-cache.js`、`src/sky-detail-cache.js` 和 `src/earth-elevation.js`。

## 中国星官的资料与显示边界

- 当前中国体系采用清代通行整理，32 个天区包含三垣、二十八宿和近南极增补区，共 300 个独立星官与 12 个附属星官；本体成员构成成员图和连线，有名增星另计、可搜索，不推造增星连线；不声称是汉唐原貌或宋代某年星图的复原。
- 文化体系改变组织、名称、连线与教学意象，不改变模拟时刻、恒星真实身份或所选星空影像。HIP、Gaia 与星团对象保留各自的类型和目录标识。
- 星官数据按来源中的已识别成员绘制；312 条目录记录各有独立插画，保留成员图。现有 312 幅星官插画和 7 幅四象／三垣总览，均为现代教学意象，来源与许可独立于星官数据。两类插画分别控制，总览默认关闭，同视图允许重叠；独立透明度默认 20%，只影响四象、三垣。详见[数据说明](../assets/chinese-sky/README.md)与[图像说明](../assets/chinese-sky/art/README.md)。
- 主画面、巡天和照片共用体系与类别；当前来源偏好、场景和环境收藏可恢复体系。缺少该字段的旧场景采用西方；不为中国体系复用 IAU 边界或推造精确宿界。

## 数据年代、模拟时刻与显示精度

| 内容 | 当前依据 | 理解边界 |
| --- | --- | --- |
| 空间站轨道 | OEM位置/速度，区间内局部8点拉格朗日插值，区间外拟合近地SGP4或长期J2接续 | 主场景与所有观测共用轨道；区间外注明延续演算，不包含未知机动与未来阻力变化 |
| 东方红一号 | 现代根数使用SGP4；历史阶段使用报载参数和过境记录重建 | 拟合与独立实现核对不等于真实遥测或测量误差保证 |
| 高度、经纬度和姿态读数 | 6371 km球体、地心坐标和既定参考方向；天文计算使用已说明的近似 | 新增显示高程不把轨道读数改为精密椭球高，也不增加落地物理 |
| 城市影像 | 内置2025年Sentinel-2年度合成，原始约10 m；不同城市按实际源显示 | 年度合成不是某一天的实时照片，放大不生成街景或独立建筑模型 |
| 显示高程 | ETOPO 2022全球底座；GLO-30 2023_1产品，主要观测2011—2015，部分补缺更早 | 原始约30 m DSM、EGM2008高程；实际精度受网格层级限制，1×高度不垂直夸张 |
| 高清星空 | DSS/Pan-STARRS历史光学巡天、JWST精选红外影像及原银河底图 | 每源有覆盖与波段，2022年JWST红外颜色映射不是肉眼真彩或实时天空 |

| 云图、极光与视觉现象 | 各源观测/预报时次，结合程序化云层、极光、气辉等渲染 | 观测覆盖、预报和视觉近似分别说明，缺覆盖不伪造为实时全球观测 |

## 本批验证状态与后续维护

本批实际结果、摘要和未运行项见[v1.23 实测记录](v1.23-validation.json)；v1.20 的历史通过结果不作为本批结论。后续改变能力、默认值、格式、来源或保存范围时，同批更新对应条目、操作和测试映射；内部修复保留稳定ID，在更新记录与验证中说明。

生日星空卡支持1901–2100年公历生日、回归黄道十二宫和声明口径的传统值日二十八宿，40项文化解释及80条现代祝福。纪念图不表示出生地实际可见天空；规则与边界见[日期来源](birthday-calendar-sources.md)。

白天地表默认采用2026 Q2原生500米级MODIS时间合成，保留1公里和2004 NASA图源可切换。各地球视图共享图源和四片细节缓存；海岸采用细分遮罩，海面与缺测使用明确来源的后备影像。[数据口径](../assets/earth/day-2026-q2-500m/README.md)。

地表漫游当前是观察相机移动；飞机气动、火箭发射分级和跨行星驾驶不属于此版本的飞行动力学。局部地形与历史星空的计算口径见[世界视图说明](world-explorer.md)。

## 天体观测与主要卫星

v1.32支持火星多图层三维探索、地面圆面观测、地球图层与地表联动、同视场日期及图层比较、事件查询和来源落款导出。地表图层为实测历史镶嵌；模拟时钟控制几何与照明。主要卫星提供基础形体和轨道系统，详见[口径](planetary-observatory.md)。

## 地球观测专题

地球支持可见光、近红外、短波红外、昼夜地表温度、高程及海底深度概览；USGS历史矿点可独立叠加、按矿种筛选和查询。新增遥感地图内置固定八日数据期，不随模拟时钟生成新观测；矿点数量不代表储量。图层可左右比较，拍照保留图例和来源。[操作](../使用说明.md#地球多光谱高程与矿产) · [数据](../assets/earth/observation/README.md)。
