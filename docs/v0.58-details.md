# v0.58 — 体积极光 / Volumetric aurora

8K 极光改用有厚度的发光体积。卷曲亮弧、较宽弱光、局部高度起伏和向上展开的透明光幕共同构成层次。绿色为主体，高处带淡红光，局部底缘带粉紫色。4K 继续使用原有九层曲面。

## 形态依据

对照 NASA 的五组空间站照片和延时影像，研究极光发光机制、磁场方向、高度与颜色、近处薄幕及远处亮弧。[原理、照片及来源](aurora-research.md)。照片用于研究，不随安装包分发。程序根据这些特征生成光幕；NOAA 网格提供活动范围与强度。

## 计算与资源

- 1024×512 RGBA8 纹理同时缓存两个半球的发光分布，带 mipmap。播放中最多每秒刷新 4 次；换来源或暂停跳时立即刷新。
- 体积只积分 90–360 km 可见球壳，跳过下方空区，在地表截断。每段 24 步，性能保护为 16 步；穿过两段时最多 48／32 步。
- 极光缓冲区采用半分辨率，性能保护比例为 0.35；两者都限制在 960×640 以内。大屏触及上限时，性能保护仍通过减少步数降负载。
- 地球、云图、星空与模型继续使用原画质。极光缓冲使用半浮点，并在统一 HDR 色调映射之前合成。
- 镜头、光线和时间不变时，复用已积分的极光画面，仅合成一次。需积分时两次绘制，形态更新帧增加一次小纹理绘制。
- 专属纹理最大约 7.4 MiB，包括半浮点画面、带 mip 的发光分布、小噪声及高度剖面。无新增图片下载。关闭或退出 8K 时释放专属资源，共享的 NOAA 和大气纹理继续由原模块管理。
- 不支持浮点缓冲或着色器失败时恢复经典极光。

## 验证

- 单元检查：时间循环、缓冲尺寸预算、噪声可复现、颜色高度顺序、资源归属、释放和回退。
- 浏览器检查：4K 身份保留、8K 初始化、暂停缓存、跳时重现、午夜连续性、高倍速更新节流、NOAA／全零网格、场景恢复、HDR 回退、重复画质切换、DPI 上限、GL 状态与浮点能力回退。
- 视觉对照：俯视、地平线、低轨斜视、两半球和昼侧。移除规则细丝，减弱平行副弧，增加局部卷曲与高度展开。
- subagent 审查修正了半球纹理 mip 边界、外壳顶端渐隐及午夜噪声连续性；视觉审查用于调整重复轮廓和近景疏密。

## 本机 GPU 抽样

使用 WebGL GPU timer query，1280×900 绘图缓冲、640×450 极光缓冲；每模式预热 5 帧、采样 15 帧，交替测量。预先绘制地球深度，仅测极光工作；形态纹理已缓存。测量不包含整帧、云层或每秒至多四次的形态更新。

| 视角 | 原九层极光中位数 | 新体积积分及合成 | 静止缓存合成 |
| --- | ---: | ---: | ---: |
| 极区俯视 | 17.51 ms | 5.15 ms | 4.28 ms |
| 地平线 | 10.04 ms | 4.07 ms | 3.11 ms |

本次抽样没有 GPU disjoint。具体数值随设备与视角变化；原始结果及 p90 见 [测量记录](v0.58-performance.json)。复查时先运行 `tests/browser/aurora-volume-views.js` 设置相机，再运行 `tests/browser/aurora-volume-performance.js`；功能检查使用 `tests/browser/aurora-volume.js`。
