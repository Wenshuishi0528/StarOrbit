# v0.61 — 夜面也显示云层 / Night-side cloud visibility

在“云图与极光”设置中新增“夜面也显示云层”，默认关闭。开启时云层使用不随太阳方向变化的颜色，保留云图覆盖、透明度、体积密度与动态变化。普通云层（2K/4K/8K）和 8K 体积云均支持；关闭后恢复现有昼夜光照。简易画质无云层，控件随云层控件一起禁用。

选项随本机设置、环境预设和分享场景保存。旧场景/旧预设没有此字段时按关闭处理；场景格式检查拒绝非布尔值。跟随与轨道总览、不同航天器任务共用同一套地球设置。“显示云层”总开关与云图来源“关闭”仍控制云层是否存在。

The optional setting removes solar illumination and solar-dependent aerial tint from cloud shading, while preserving coverage, alpha and volume density. Existing illumination remains the default. Both regular and volumetric cloud materials share the option; legacy scenes and presets default to off.
