# v0.63 — 深夜云层接近黑色 / Nearly black night clouds

用户澄清：夜面云应当基本不可见，呈黑色或很深的灰色，不要为了显示轮廓而提亮成白灰。

- 取消 v0.62 的 800 倍月光显示增益。月相、距离、月食和地球地平线遮挡仍有效，使用原始相对太阳辐照度。
- 2K/4K 普通云的固定 0.004 环境项，以及 8K 体积云的固定 0.002 环境项，在太阳方向余弦 -0.16 到 0 之间平滑衰减；深夜为零，日面保持原值。保留太阳照射下的晨昏云、云密度、透明度和遮挡。
- 四语提示说明夜云接近黑色且不会额外增亮。原有保存、预设、场景兼容保持不变。
- 修正旧隔离测试将 standard 误设为 enhanced=1 的问题；实际 4K 与 2K 均使用 enhanced=0。

验证：全套 npm test、离线和网页构建、网页资源检查通过。54 项浏览器检查覆盖六个渲染配置、月落、无月光、保存与重载。最大 UI 曝光 2.5 下，隔离深夜云层通过真实 ACES/sRGB 和 HDR 合成后，中心 64×64 区域每个 RGB 字节均为 0/255（验收上限 2/255），测试月光输入 4e-6。此值是特定测试画面，不代表所有晨昏或闪电场景。日面开关逐像素一致。详见 [检查结果](v0.63-validation.json)。

实际地球的夜面、晨昏和日面截图已检查；夜面云基本不可见，晨昏云随日照渐亮。原有自然闪电和大气夜光仍可存在。本次不引入全球自动曝光，不声称完整光度定标。

Removed the artificial lunar visibility boost and the fixed deep-night ambient fill. Night-side clouds remain nearly black at daylight exposure. Solar lighting and cloud opacity/occlusion are retained. All tests and builds passed, with 54 browser checks including final display bytes at maximum exposure. Standard-quality coverage now uses its actual production shader branch.
