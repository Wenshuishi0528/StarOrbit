# 轨道视角的大气方向性核对

2026-10-23，本地更新，未发布版本。

## 结论与修改范围

观察位置必须使用模拟中的轨道相机。散射规律与地面相同，但光路不同：轨道观察者位于主要可见光散射层之外，视线沿地球边缘穿过不同高度的空气。不能把地面天空渐变贴在地球周围。

400 km 高度的几何地平线约低于当地水平面 19.8°，因此测试中的太阳高度角 −19°属于轨道近地平线情形，并非地面已经入夜 19°的同一种视角。运行时相机高度来自现有轨道和观察位置，400 km 只是检查用例。

| 条件 | 应有表现 |
| --- | --- |
| 白天、较短太阳光路 | 大气以蓝色为主；朝日气溶胶前向散射可形成较白的亮晕 |
| 轨道晨昏、掠过低层空气 | 短波更强衰减，低层可偏橙红，上层可保持蓝色 |
| 同一轨道位置转向侧面或背日方向 | 光路和散射角一起变化，颜色与亮度不能复制朝日方向；也不能强制所有背日方向都黑暗 |
| 地面入影而云顶仍见太阳 | 高空云层可以延迟变暗；应按云层高度计算地球遮挡 |
| 深地影 | 太阳单次散射很弱；气辉、极光是不同过程，不能用橙色太阳散射环代替 |

审查发现大气已有正确的方向变量与相函数；主要不一致处是普通云与体积云依赖太阳高度的人为橙色染色。此次保留已正确的轨道几何，把 8K 大气、地表直射光、云层及海面太阳反光统一接入同一个 RGB 太阳光路表；云顶按实际采样高度计算受光。4K 与较低模式保留原有着色。

## 依据

- Bruneton & Neyret, *Precomputed Atmospheric Scattering*, 2008，DOI [10.1111/j.1467-8659.2008.01245.x](https://doi.org/10.1111/j.1467-8659.2008.01245.x)。核对了作者的[更新实现与公式](https://ebruneton.github.io/precomputed_atmospheric_scattering/atmosphere/functions.glsl.html)：观察天顶角、太阳天顶角和视线/太阳夹角是不同变量；光路透射按波段变化。
- Hillaire, *A Scalable and Production Ready Sky and Atmosphere Rendering Technique*, 2020，DOI [10.1111/cgf.14050](https://doi.org/10.1111/cgf.14050)。读取[作者论文 PDF](https://sebh.github.io/publications/egsr2020.pdf) 第 3–5 节的输运方程、气体模型和查找表方法，以及第 6–7 节的误差与成本讨论。这里只复用其物理思路，没有声称实现论文完整多次散射算法。
- [NASA：Smoke in the Stratosphere](https://science.nasa.gov/earth/earth-observatory/smoke-in-the-stratosphere-148276/)，ISS 约 400 km 高度的边缘观察，解释低层橙色与高层蓝色。照片含特殊烟层且经过对比度增强，用于核对机制，不作为默认颜色的逐像素目标。
- [NASA：Orbital Sunrise](https://www.nasa.gov/image-article/orbital-sunrise/)，展示轨道视角下低云暖色、高云亮白及终止线/轨道几何的影响。高层夜光云不是本次普通气象云模型的一部分。
- [NASA PSG 大气模型说明](https://psg.gsfc.nasa.gov/helpatm.php)，核对分子散射与气溶胶前向散射的角分布区别。

## 验证与成本

- `npm test` 通过；离线 HTML 构建通过，约 211 MB。
- 单一 Chrome WebGL 上下文，800 × 560，按需绘制；采用生产着色器与小合成云遮罩，不加载整套 8K 素材。
- 400 km 观察高度，太阳高度 45° / −19° / −45°，视线方位 0° / 90° / 180°，九组大气取样完成。检验前向散射、侧向蓝色、晨昏方向差异、地影遮挡、云顶延迟入影与共同旋转不变性；全部通过。
- 普通云、体积云与地表生产着色器实际编译通过。合成云纹理只用于核对着色，不代表真实天气数据或最终云图清晰度。
- 重用已有 256 KiB 太阳光路表，没有新增大纹理、屏幕渲染目标或每帧 CPU 预计算。云/地表每次受光采样增加一次查表和 RGB 指数衰减；未据此声称全应用帧率不变。
- 可复现浏览器检查：将 `tests/browser/atmosphere.js` 用 esbuild 打包到本地服务目录，并配套复制 `tests/browser/atmosphere.html`；打开后点击“运行方向检查”。

## 精度边界

这是固定气体/气溶胶剖面的 RGB 单次散射近似。没有加入实测气溶胶分布、折射、多次散射或自然气辉。背景仍使用已有透明混合与显示色调映射，尚未改成完整的线性 HDR、逐波段透射合成；本次验证证明方向和受光逻辑一致，不等同于辐射定标。完整大素材应用未在本轮做长时间压力测试。
