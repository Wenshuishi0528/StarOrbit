# v0.65 — 新版东方红一号模型 / Revised DFH-1 model

以已确认的v0.10米制整星GLB替换任务目录中的v0.03旧资产。新文件为 `assets/spacecraft/dongfanghong1_v10_meters.glb`，3,721,716字节、65,472场景三角面，SHA-256：`3b40f8c572a3d0a0f06f0de644e7756d6301ab950b4fa1651d4a44c430969d79`。

模型仍为Y-up、每模型单位1米。现有加载器绕X轴+90°并缩放为每米5查看器单位；不使用1:50打印坐标。名义本体直径1m，完整天线跨度7.067m。轨道、遥测、自旋和手动姿态代码未改。

保留A8/B4/R4/P1/H1/L4/S2配置：两类槽天线为一字结构，地平仪单台且有下缘折面，长天线接到z=-0.038m的L根座，两个太阳角计位于上下壳体。新铭牌使用用户指定GLB轮廓的平顶重建，包含原图颜色贴图；红底为单一顶面。所有几何细节仍是参考资料约束下的模型，并非制造图纸。

Node轴向测试读取真实新GLB几何，纹理加载钩子只跳过Node环境缺少的图像解码；实际图像解码和显示在浏览器验证。既有姿态、120rpm自旋与任务隔离回归继续运行。网页构建检查比较解压后的GLB与当前任务目录资产的完整字节，而不只检查GLB文件头。

最初完成本机源码、离线/网页构建与桌面运行目录更新时，尚未发布 GitHub 或在线站点。用户随后授权上传最新版本，使用 main 分支与现有 GitHub Pages 自动部署流程发布 v0.65；便携 Release 保持 v0.38。模型与本地验证记录见 `v0.65-validation.json`。

已完成：完整单元测试、网页/离线构建、网页资产逐字节一致性、已安装离线HTML中GLB解压字节核对、桌面启动器与签名核验。可用的应用内浏览器中完成实际显示、铭牌颜色贴图与空间站↔卫星切换核验。截图临时开启辅助照明；完成后恢复照明、轨道读数、小地图、时间轴和现实时间选项。
