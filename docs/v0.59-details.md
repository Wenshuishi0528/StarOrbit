# v0.59 — 东方红一号音频播放修复

## 原因与修改

播放器读取音乐库后会立即随机播放一首背景音乐，随后才等待模型和任务恢复。若保存的任务是东方红一号，加载期间便会先播放普通音乐，再切到专属录音。新增回归用例在 v0.58 上能复现这一顺序错误。

现在音乐库先完成准备，确认当前航天器后才自动播放。东方红一号直接启动专属音频；其它任务仍随机选择首曲、按列表顺序循环。

同时收紧异步事件：仅当前资源真正结束时才推进播放，5 秒重播回调检查播放代次。切换、暂停后的旧事件不能改变新播放状态。保留同一个媒体元素及原录音文件；[WebKit 自动播放说明](https://webkit.org/blog/7734/auto-play-policy-changes-for-macos/)说明自动播放授权按媒体元素授予，因此连续播放继续复用该元素。
