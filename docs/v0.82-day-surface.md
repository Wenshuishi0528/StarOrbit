# v0.82 · 可切换的白天地表

> **版本专题／历史证据**：本文保留历版设计与当时检查，部分章节含后续补充。现行功能与操作见[使用手册](../使用说明.md)，验证范围见[验证指南](verification.md)。文中的旧版本结果不代表当前版本重新验收；标为源码的链接需联网查看对应提交。

> 历史记录：本版的源条带和显示 RGB 作为反射率的问题已在后续诊断中确认。当前来源和处理已由 [v0.83](v0.83-surface-radiometry.md) 替代；下文描述 v0.82 当时的实现。

“地球与星空 → 白天地表”提供 2026 第二季度约 1 公里版（默认）与 NASA 2004 原版。夜景 2024 / 2016 选择独立保留；所有年份选择会保存。

## 来源与色彩

数据为 Copernicus Sentinel-2 Level 3 Quarterly Cloudless Mosaics，2026-04-01—2026-06-30，RGB = B04/B03/B02，DN / 10000 为反射率，-32768 为缺测。使用 [Taylor Geospatial 的公开镜像](https://source.coop/tge-labs/sentinel-2-quarterly-cloudless-mosaics)；原始季度清单、日期、处理参数和显示文件哈希记录在资源 manifest 中。原产品为各波段独立选取季度有效观测第一四分位数，不是同一天拍摄的全球照片。

使用 [Sentinel Hub basic True Color](https://custom-scripts.sentinel-hub.com/custom-scripts/sentinel-2/true_color/) 基础显示映射为 RGB = clip(2.5 × DN/10000)。最大通道反射率在 0.20—0.40 间时，以 smoothstep 连续过渡到 Sentinel Hub 季度 True Color 的亮部压缩，保护沙漠与雪地细节。规则对全球一致，不对中暗地表再施加提亮 gamma，不逐块直方图均衡，不人工涂绿。贴图仍按 sRGB 读入，由原有地球着色器应用日照。源影像真实高反射积雪保留。

海洋和主要湖泊沿用 NASA 水体；使用软件现有陆地/湖泊矢量面生成约 2 km 遮罩并平滑海岸，避免近海源影像覆盖边界形成方块；源数据无有效观测的陆地和极区使用 2004 补充。coverage.png 表示采用 2026 像素的区域。新旧年份在采集季节、合成方法、显示色彩和原图地形阴影上均有差异，不能将颜色差直接解释为环境变化。

## 体积与加载

全球网格 43200×21600，30 角秒，赤道约 928 m。COG 的缩略层按有效值平均至约 1 km UTM 网格，再重投影为经纬度网格；JPEG 质量 83，并保留相邻像素边缘以保护分块接缝。新增显示 JPEG 共 **52,867,171 字节（52.87 MB）**，包含 288 块细节和四档底图；最终包只含显示图片和清单，不含 10 m 源影像或处理缓存。完整离线 HTML 约 366 MB，分离资源本机版约 274 MB。

中等、标准、精细画质按当前视角保留最多四块白天地表细节；简易档仅载入低分辨率底图。切换地表不会重新载入夜景和云层；基础图成功载入前保留当前地图，失败则恢复原选项。快速切换只提交最后一次选择，并丢弃旧来源在途细节。

## 验证

检查源季度完整性、全部分块 SHA-256、颜色固定参考值、经纬度与日期线注册，并在浏览器中检查切换、失败回退、快速切换及选择持久化。两名 subagent 分别审查切换实现与最终画面；涵盖美洲荒漠、农田、亚马逊、撒哈拉、极区、东海/黄海和五大湖，以及实际地球渲染。18 项日/夜切换浏览器检查通过，精细画质 WebGL 错误为 0。
