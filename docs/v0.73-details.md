# v0.73 夜景清晰度

现场 Safari 的 8K 模式下，四块夜景细节纹理已加载，尺寸均为 1816×1816，失败列表为空。加载成功不等于所有屏幕位置都使用完整的高清数据。

旧 shader 根据屏幕像素在基础 8K 图上的最长投影，将高清块再次混回基础图；斜视时一个方向被压缩，另一个方向仍需要高清，该规则也会压掉后者细节。现在加载完成的高清块只作进入画面的渐显，缩小与斜视交给 textureGrad、mipmap 和各向异性过滤处理，不使用锐化或提高曝光伪造细节。四块缓存与按视野加载保持不变。

夜景细节来自既有 NASA Black Marble 数据，显示图约 1 公里像素尺度；超过这个尺度的近距离放大仍会看到原始数据的光斑，不代表贴图未加载。四块缓存优先覆盖视野中心，不保证宽阔视野的所有区域同时具备最高细节。

验证：地表分块与经纬度配准、资源释放、环境与渲染测试通过；离线、本机轻量和网页构建通过。Safari 正式本机地址显示 v0.73，运行时确认新着色器生效，WebGL error 为 0，没有编译失败的程序。未进行街道级清晰度承诺或量化清晰度评分。
