# v0.60 — 完整轨道总览 / Complete orbit overview

## 原因 / Cause

轨道总览原来始终取当前时间前后各 2,800 秒，总计 93 分 20 秒。这个固定窗口接近空间站周期，却不足以覆盖东方红一号一圈。2026-10-28 10:40:40（UTC+8）的内置轨道演算周期约为 109.49 分钟，旧版轨道线首尾相距约 7,059.52 km；历史轨道的指定周期则是 114 分钟。

The overview used a fixed 5,600-second window for every mission, omitting a substantial arc of DFH-1's longer orbit.

## 修改 / Change

- 直接从当前轨道模型取得椭圆几何：半长轴、偏心率和轨道平面方向。历史轨道使用既有历史椭圆；星历区间内使用当前位置和速度确定的瞬时密切椭圆；区间外使用实际演算所用的端点椭圆。
- 沿偏近点角 0–2π 均匀绘制 360 个顶点，使用 `THREE.LineLoop` 自然闭合。计算量不随轨道周期增加，不再指定轨迹时间范围或拼接首尾端点。
- 总览表示当前时刻的完整轨道形状。受摄动轨道的未来真实轨迹可能偏离当前密切椭圆；图线不是未来一圈星历的时间采样。
- 跨越 2000 年的历史／现行轨道切换时，整体换为当前年代的完整椭圆，不把两个年代的轨迹画进同一个环。
- 保留日照／地影配色和刷新节流。星历、卫星位置、轨道传播、带时间含义的地面轨迹及事件时间不变。无可用椭圆时不伪造闭合路径。

The overview now draws the active ellipse geometrically, using 360 eccentric-anomaly samples and a closed line loop. It uses the historical ellipse, the current ephemeris state's osculating ellipse, or the propagation endpoint ellipse as appropriate. It shows current orbit geometry rather than a timed future trajectory. Era changes replace the entire ellipse; ground tracks retain their existing time semantics.
