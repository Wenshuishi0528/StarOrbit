# v0.88 云图库与下载

入口统一为“地球与星空 → 打开云图库…”；“数据与资源”中的云图按钮打开同一个窗口，不再叠加两层弹窗。

## 使用

- 默认打开**已保存云图**。本机与浏览器中的相同 SHA／时次合并为一行，不同内容修订保留；已有本机图点“使用此云图”即完成读取、校验和应用。
- 顶部固定显示实际加载成功的**当前使用**，与列表、侧栏和资源总览一致。使用失败保留上一份图与设置。
- **下载新云图**查询官方目录，按月份和可用日期列出已发布时次；不再自动逐日回查，也不需手填猜日期。查询可停止，失败显示原因；已有图始终可使用。
- 下载前显示约 220 MB 的科学字段预算，进度报告字段数量、传输量、覆盖检查、8K 转换和保存。下载不改变模拟时刻或当前云图，完成后可预览再使用。
- 内置图一键切回；本地生成与关闭放在“其他显示方式”。旧最新／自动历史模式在恢复设置时固定为匹配的已保存图，无匹配则使用内置图；旧场景与收藏引用继续兼容。
- GitHub 旧图仍可手动比较；VIIRS 旧扫描预览继续留在其他数据历史，不作为完整全球云图。

## 保存和任务

NASA 完成图与元数据原子保存到 `~/Library/Application Support/Tiangong Orbit Simulator/clouds`。启动下一时次不会回收上一份已完成图，浏览器关闭也不会丢掉完成结果；相同时次的完整本机文件可直接复用。

下载由本机服务运行。返回模拟器或关闭图库不停止任务；页面重开会查询并接回仍在运行的下载。服务本身重启会明确报告中断、允许重试，未承诺跨服务重启的科学字段断点续传。不同本机地址分别保存任务状态，共用完成图库。

取消按钮只控制下载，目录查询另有“停止查询”，应用／收藏／导出不显示虚假的取消按钮。取消须得到服务端确认；停止失败保留“重试取消下载”，不会启动下一份任务。已使用图和完成图库不会因取消被清除。

浏览器副本仍受原有缓存容量管理，当前使用、收藏、预设引用以及两代合格备份受自动清理保护。容量不自动清理本机完成文件。“移除此浏览器副本”只删浏览器记录；原有“清理下载缓存”中的云图清理会同时清除本机文件。导入／导出保持原 JSON 快照格式。

## 检查

文件尺寸、解码、实际 SHA 及有效数据仍校验。图像平台、接缝及局部缺测作为可见警告，允许明确手动使用；这不表示气象质量得到保证。NASA 有效性通道的静态后备保留，并修复透明行质量抽样复用上一行像素的问题。

元数据检查、极光和轨道更新并行运行。慢目录不会阻止其他更新，错误保留本机服务返回的原因。云图下载和应用可独立进行，下载时仍可使用其他本机旧图。
