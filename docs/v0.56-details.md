# v0.56 · 主要城市标注

在“地理与星图 → 地球地点标识”中新增“主要城市”开关和“城市层级”选择。启用地点标识后，主要城市默认显示一级；可逐步增加二级、三级。首都保持独立开关，同一座城市共用一个标注位置，北京继续使用红色五角星。

## 数据与层级

城市坐标、名称采用 [Natural Earth 1:50m Populated Places v5.1.2](https://www.naturalearthdata.com/downloads/50m-cultural-vectors/50m-populated-places/)。该数据以区域重要性和地图比例等级筛选城市。软件的一级、二级、三级是地图显示层级，按源数据 `SCALERANK` 分组：

- 一级：0–2，共 186 个城市位置。
- 二级：3，新增 336 个城市位置。
- 三级：4 及以上，新增 688 个城市位置。

共 1,210 个城市位置，其中 199 个同时属于现有首都分类；科学考察站与历史遗址不归入城市。选择二级包含一级，选择三级包含所有三级；首都开关可以独立显示首都。名称根据缩放、密度、地球遮挡和可用画面空间显示，切换等级增加候选城市。

数据包保留中、英、俄、法名称；来源缺少对应译名时沿用英文名。源文件 URL 与 SHA-256 继续记录在 `assets/geography/atlas.json`。新增城市数据约 166 KB（未压缩）。中国官方边界、海上线段、国家与地理区域数据保持原样。

重建城市部分：`python3 scripts/prepare-geography.py --cities-only`（依赖 `scripts/geography-requirements.txt`）。全量重建仍使用原命令。

## 运行方式

- 城市与首都共用字形图集及同一个批量绘制对象，不新增绘制批次。
- 沿用视野筛选、标注避让和每屏最多 96 项的总上限。
- 静止画面复用布局和 GPU 缓冲；移动中的布局刷新沿用每 0.2 秒一次的节流。
- 切换等级不重建字形图集；仅更新候选标注及布局。
- 城市开关与层级随本地设置、预设和场景保存；旧设置自动补入默认一级。

## 验证

数据与设置测试覆盖三级筛选、旧设置默认值、非法层级、首都去重、北京标志及城市坐标。浏览器检查覆盖三级切换、关闭、四语显示、场景恢复、跨航天器共享、静止复用及绘制上限。

实测结果：完整 `npm test` 与网页构建检查通过；原有地理浏览器回归 24 项、城市专项 28 项通过。中国视角三级候选数分别为 46／87／214，字形图集仍为 2048×2048，全部地理图层最多六次绘制。四语、刷新后记忆及 390px 窄窗口检查通过。
