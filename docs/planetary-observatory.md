# 天体观测：数据与计算

适用版本：本地 v1.32。操作见[使用说明](../使用说明.md#天体观测)。

## 统一入口与时钟

火星和地球共用主渲染器，关闭时释放独立图层，保留环境拥有的地球纹理。太阳使用已有巡天／SDO界面；月球使用已有月球工作台，交接时间与地点。模拟时间使用UTC毫秒，界面标明UTC+8。修改时间改变几何和照明，实测地图保留各自采集年代。

## 火星

体固坐标为x轴零经线、y轴东经90°、z轴北极，东经为正。纹理左缘−180°、右缘+180°，上北下南。观测方向采用地面接收时刻、目标发射时刻和光行时；自转轴与本初子午线使用Astronomy Engine的IAU模型。观察相机采用实际距离／半径、输入角秒视场和天球北方方向，所以两个日期的圆面比例能直接比较。

五种图层分别来自Viking可见光、THEMIS日间与夜间热红外、MOLA高程和USGS 2014全球地质GIS。地质数据按原投影重投影到经纬网，保留官方配色；地图图例没有贴到球面。MOLA地形按实际米值起伏，默认不夸大。热红外灰度为历史镶嵌强度，夜间数据极区缺测保留有效性。原始源、处理步骤、哈希、地图与地名目录见[火星数据说明](../assets/mars/README.md)。

## 地球

日间、夜间和云层借用当前环境纹理，高程取现有全球底座。地名搜索使用已有Natural Earth目录。选择球面地点后进入原地表模块，由地表模块继续按需载入局部地形。云图库、快照与缓存均为既有实例。

## 卫星与事件

[卫星数据说明](../assets/satellites/README.md)记录20颗主要卫星目录、JPL内核、2026—2030年子集范围、TDB换算、量化误差与校核点。太阳系使用同历元几何位置；地面观测及事件计算处理光行时。显示增强只改变视觉半径，轨道距离仍为实际比例。火卫一、火卫二使用轴比椭球表示基础形体。

火星冲、日月食采用Astronomy Engine搜索；日月食按地点和地平线过滤。木星四卫星扫描未来七天的凌、掩、食与影凌，包含光行时、母星扁球与太阳半影几何，分块让出界面并支持取消；事件按分钟显示。事件属于观测导航，卫星基础渲染尚未模拟完整的相互掩食光度和表面投影阴影。

## 验证

模块测试覆盖独立Horizons观测基准、火星冲日期、已知日月食、四类木星事件、双栏视直径与边缘可见性、MOLA奥林帕斯山／希腊盆地坐标、卫星原始SPK样本与独立Horizons数据。实际执行与浏览器检查见[验证总览](verification.md)。
