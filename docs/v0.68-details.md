# v0.68 — 数据与资源

![本机 v0.68 资源中心](v0.68-resources.png)

## 使用

右上角 **数据与资源** 是统一入口。左栏 **公共资源与轨道 → 打开数据与资源** 和 **云图下载与更新…** 也会打开同一面板。

- 云图卡片选择 NASA SATCORPS 或 Live Cloud Maps · GitHub；极光使用 NOAA SWPC · OVATION；轨道只检查当前航天器的数据源。
- 每张卡片分别显示最新下载、当前画面实际使用的数据和上次检查时间。**检查更新** 获取并校验数据；**使用最新下载** 切换显示。已经跟随该来源最新数据时自动应用新版本；固定历史、内置和关闭状态保持原选择。
- **检查全部更新** 并行检查三项，各自报告结果。一项失败不会使其他项停止。地表、夜景、星空、月面和地理素材随软件版本提供，不参与天气与轨道检查。
- 下载历史保留收藏、取消收藏、使用指定版本、导出、导入与删除；跨任务轨道显示所属任务，使用前需要切换到对应航天器。

## NASA 更新如何完成

桌面启动器提供本机服务。服务从最近 30 天的每日全球合成产品由新到旧筛选，检验全球与两极覆盖，再读取云层字段生成 8192×4096 图片。图片具有源地址、观测区间、分辨率和 SHA-256，前端校验后保存并按当前选择应用。更新期间保持原图。

“已是最新可用数据”只用于完整检查后的无变化结果。较新候选访问失败时标为 **检查不完整**，不能据此宣称源端没有更新；完全失败时显示错误并保留已有数据。已有结果恢复与手动更新共享状态，避免重复任务。完整成功检查在 15 分钟内复用，仍显示实际检查时刻，不用点击时刻冒充重新检查。

网页版保留 NASA 选项、导入与历史使用；NASA 在线处理按钮说明需要桌面服务。其他外部数据能否直接下载取决于来源的网络与跨域策略。不可访问时给出桌面更新或导入的替代路径；不绕过来源限制。

## 缓存规则

**自动限制下载缓存** 默认开启，可关闭。默认容量 200 MB，可调整为 20–2000 MB。合并计算当前浏览器保存的全部云图、极光和各任务轨道，以下载时间从旧到新淘汰。

容量自动清理保护当前正在使用、正在下载或解码应用、已收藏、各任务所选轨道及环境收藏明确引用的快照。受保护数据本身超过预算时保留并提示。写入配额不足时只在自动清理开启的情况下清理安全旧记录并重试一次；失败不替换当前数据。批量淘汰在一个 IndexedDB 事务中完成，失败整体回滚。

浏览器存储按地址隔离。本机 NASA 公共库另行显示实际磁盘用量，沿用最多两份派生图片的保留规则；它不计入浏览器容量。自动清理开关控制浏览器容量策略。手动清理可明确选择资源类型及是否包含收藏，清理期间不会被启动恢复任务重新写回。

## 计算与下载开销

- 同一来源的重复点击合并为一个任务。HTTP 校验信息相同则复用缓存；无法从响应头判断时比较内容哈希，避免重复保存和解码。
- 相同轨道根数不重新采样，相同星历不重建轨道；较旧的源端数据不会覆盖已有较新数据。
- NASA 覆盖筛选和完整成图复用已经读取的数据块，减少同一候选的重复网络读取。
- 下载进度限频刷新。历史列表折叠或资源面板关闭时不生成缩略图；图片解码串行执行。打开资源面板时暂停后台三维渲染，关闭后重置帧时间基准。
- 请求有超时和响应大小限制；来源缺少可靠长度时只显示已下载量，不编造完成百分比。

## English

The Data & resources panel brings cloud, aurora and mission-specific orbit updates together, with separate downloaded, active and checked states. Complete unchanged checks, incomplete checks and failures are distinguished. NASA processing still requires the local desktop service; web users can import its snapshots.

Automatic browser-cache cleanup is enabled by default and removes the oldest unprotected downloads across all resource types. Active, in-flight, starred and referenced snapshots are retained even above budget. NASA's shared local derivative-image library is measured separately. Repeated requests, identical payloads, unchanged orbital elements and NASA data blocks are reused; history previews and background 3D rendering avoid unnecessary work.

Source, web and portable builds share v0.68. Publication uses the main branch, the existing Pages workflow and GitHub Releases.
