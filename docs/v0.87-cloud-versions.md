# v0.87 云图版本

> **版本专题／历史证据**：本文保留历版设计与当时检查，部分章节含后续补充。现行功能与操作见[使用手册](../使用说明.md)，验证范围见[验证指南](verification.md)。文中的旧版本结果不代表当前版本重新验收；标为源码的链接需联网查看对应提交。

入口：**数据与资源 → 云图 → 管理云图版本…**。

一个列表合并 NASA 全球合成官方发布时次、浏览器已有云图和本机 NASA 旧档。相同时次的不同 SHA 文件分别保留；旧 GitHub 档案也可以手动对比。日期下拉来自已列出的官方日期，不再要求猜日期试下载。

## 操作

1. **刷新版本列表**只读取官方目录和本机元数据，不下载云图/科学字段。NASA 默认列最近三个目录日期，选择下拉中的更早日期可列出当天全部整点时次。
2. 选择版本，查看来源、UTC 时次、缓存位置、大小和检查提示。本机已有的版本无需重复联网下载，可直接载入浏览器缓存。
3. 下载完成后预览，再点**加载到地球**。下载本身不切换当前图。界面显示“正在使用”；可选择其他版本或**使用内置静态云图**切回。
4. 可收藏、导出 JSON 快照及重新导入。同一时次的不同文件修订不会互相遮盖。收藏和当前使用的版本受缓存清理保护。
5. **取消**会中止页面请求及对应 NASA 子进程，并清理本次科学字段临时目录；停止状态未确认时保留“重试停止下载”。旧的逐日回查和云图自动重试不再由新界面启动，旧更新端点也不再发起科学下载。

## 检查与显示

- 接缝、异常亮度平台和部分覆盖作为提示，允许用户手动加载，不再整份禁止。原始缓存不被这些提示删除或改写。
- 实际 SHA 不符、文件不可解码、尺寸不支持、NASA 无有效反演，仍禁止加载。
- NASA 新下载保留有效性通道；缺测位置使用内置静态云图。已有旧灰度图没有缺测掩膜，无法补出当时观测，仍保留旧像素并提示。
- 按用户要求撤下 VIIRS：此前接入的是 2048×1024 全球浏览预览（赤道约 20 km/像素），有扫描分区与缺测，不符合完整全球合成云图要求。新版不列入正式版本、不支持加载到地球；旧试验缓存保留在其他数据历史，可预览、导出和删除。

- 有效性纹理在生成和上传时使用预乘 opacity，滤波后以 `opacity + (1-validity)*builtin` 合成，避免缺测边缘出现人为暗缝。
- 手动加载允许视觉质量提示；自动推荐仍只选择严格检查通过的 NASA 图。新手动下载不会自动加入最新模式或自动跟随模拟时间。
- NASA 全球合成的目录查询、科学转换与本机库需要桌面服务；网页版可导入并加载已下载的全球云图快照。目录故障保留已知本机版本，不假装确认有新版本或没有数据。

## 实测与审查

`tests/cloud-versions.mjs`、`tests/cloud-versions.py` 覆盖缓存合并、修订区分、日期损坏隔离、缺测混合、取消先于 POST 到达等路径；已有下载、缓存和渲染检查继续保留。

浏览器在独立 8797 地址使用本机 NASA 10 月 23 日原始缓存（SHA `5bec2cc5ad288fca8bb001431c852bcf19e9ef43bf4448c26c3ea6488f64d6df`）验证：亮度平台仍被提示，用户可手动加载到地球，原始文件不被改写。另测试真实 NASA 快照往返、取消、页面重载及窄屏，并确认 VIIRS 不再作为正式来源。生产浏览器设置不用于测试。
