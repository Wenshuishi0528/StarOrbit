# v0.41：可操作的新手引导

- 帮助保持打开，点击画面、菜单或控件时可以继续操作；关闭按钮、Esc 或完成导览用于退出。
- 帮助目录中的条目直接定位实际控件：临时展开左侧对应面板、滚动到目标，以柔和遮罩、发光圆角框和箭头标明位置。
- 说明卡自动选择目标旁的空位，避免遮挡控件；屏幕缩放、菜单折叠与滚动后同步更新。
- 简短导览依次介绍模型观察、任务切换、时间控制、地球与星图、画质、音乐。每一步可返回目录或直接结束。
- “选择画质”位于“探索地球与星空”之后，推荐最高“精细 · 8K”，指向左侧“画质模式”下拉框。用户手动选择；导览保持原有画质、时间与任务。
- 音乐引导临时展开播放器，离开鼠标后继续显示；退出引导释放锁定并恢复原有折叠状态。
- 引导结束恢复临时展开与滚动位置。内容支持中英俄法，网页版与桌面版共用。

## 性能与验证

箭头定位仅在进入条目、尺寸变化、菜单布局变化和滚动时更新，用单个 requestAnimationFrame 合并事件；没有额外的逐帧定位循环。退出时移除高亮、断开尺寸观察并取消待执行定位。

验证覆盖目录点击保持、实际画质选择、临时折叠与滚动恢复、六步导览、音乐锁释放，以及桌面 1440px 和窄屏 390px／320px 下的中文、俄语说明卡边界与控件避让。subagent 复查布局变化后的箭头同步和状态清理。
